# 优先级配置主题设计模板

## 适用场景
- 用于策略或规则表格中的新增、编辑、复制、移动等场景，配置数据在表格中的插入位置或调整既有数据的排序位置。
- 当页面存在优先级、策略优先级、策略位置、规则位置、移动到某条数据之前或之后等配置时使用。
- 典型入口包括：点击表格新增按钮后，在新增表单中配置优先级；点击表格移动按钮后，在移动弹窗中配置目标位置。

## Label 文案
- 默认文案：优先级。
- 可选文案：策略优先级、策略位置。
- 当用于批量移动弹窗时，可使用“移动到”作为弹窗内说明文案，控件本身仍按目标对象 + 位置组合表达。

## 控件结构
- 由两个选择框横向排列组成：选择框1为目标规则/策略，选择框2为位置。
- 两个选择框间距为8px。
- 选择框1自适应宽度，占据控件区域剩余空间。
- 选择框2固定宽度，刚好完整展示“之前/之后”文字和下拉图标，不拉伸。

```text
┌──────────────────┐  8px  ┌──────────┐
│ 选择框1：目标规则  │       │ 选择框2  │
│ （自适应宽度）     │       │ （固定）  │
└──────────────────┘       └──────────┘
```

### 选择框1：目标规则
- 用途：选择表格中已有的一条规则或策略名称，作为插入位置的参照。
- 类型：单选。
- 高度：32px。
- 宽度：自适应，占据控件区域剩余空间。
- 数据源：当前表格中所有已有规则或策略的名称列表。

### 选择框2：位置
- 用途：选择在目标规则或策略的“之前”还是“之后”插入。
- 类型：单选。
- 高度：32px。
- 宽度：固定，刚好完整展示文字和下拉图标即可，不得拉伸。
- 选项：之前、之后。
- 默认值：之前。
- 间距：与选择框1间距8px。

## 默认值规则

### 表格有数据时
- 选择框1默认选中表格中的第一条数据。
- 选择框2默认选中“之前”。
- 两个选择框同时显示。

### 表格无数据时
- 仅显示选择框1，隐藏选择框2。
- 选择框1的选项列表增加“首行”选项。
- “首行”含义：作为表格的第一条规则或策略插入。
- 选择框1默认选中“首行”。
- 当表格至少有1条数据后，恢复为两个选择框的完整结构，移除“首行”选项。

| 表格数据状态 | 显示结构 | 选择框1默认值 | 选择框2 |
|---|---|---|---|
| 无数据 | 仅选择框1，含“首行”选项 | 首行 | 隐藏 |
| 有数据 | 选择框1 + 选择框2 | 表格第一条数据 | 显示，默认“之前” |

## 提交行为
- 新增规则或策略提交后，根据优先级配置将新数据插入表格中的指定位置。
- 选择框1选中规则A或策略A，选择框2选中“之前”：新数据插入到规则A或策略A之前。
- 选择框1选中规则A或策略A，选择框2选中“之后”：新数据插入到规则A或策略A之后。
- 仅选择框1选中“首行”：新数据作为表格第一条数据插入。
- 移动既有数据时，提交后将所选数据移动到目标规则或策略之前或之后，并同步刷新表格顺序和优先级序号。

## 状态与边界
- 目标规则或策略列表为空时，只允许选择“首行”。
- 目标规则或策略被删除、禁用或不可用时，提交前需要重新校验并提示重新选择。
- 批量移动时，如果所选数据包含目标规则或策略，需要提示目标位置无效并要求重新选择。
- 默认策略、系统内置策略或不可移动数据不应出现在可移动目标列表中；如必须展示，应置灰并说明不可选原因。
- 提交失败时保留原表格顺序，并给出失败原因。

## Coding提示
- 推荐复用组件：横向表单项、单选下拉框、固定宽度下拉框、表格数据源映射、排序更新逻辑。
- Mock数据要求：覆盖空表格、有数据、默认策略不可移动、批量移动、目标数据被删除、插入之前、插入之后等场景。
- 状态联动：新增、复制或移动提交后，需要同步更新列表顺序、优先级序号、分页和选中状态。
