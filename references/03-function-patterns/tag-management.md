# 标签功能点设计

## 1. 功能定位

标签功能包含两类使用场景：
- 标签配置：用于在业务对象表单、表格或详情页面中为设备、策略、规则等对象选择或新建标签，通常是用户使用标签的主要入口。
- 标签管理：用于汇总展示和维护所有标签，包括新增、删除、批量删除和引用次数查看，通常作为“标签管理”按钮入口出现。

两类场景不是彼此独立的能力，而是围绕同一份标签数据源的两个使用入口：标签配置中可选择标签管理里已有的标签，也可直接创建新标签；标签管理中创建的标签会成为标签配置的候选项，标签配置中新建的标签也会同步出现在标签管理列表中。

使用时先判断需求中的标签能力属于哪类场景；如果两个场景都出现，需要同时引用对应章节，并确保标签数据、引用次数和候选项保持联动。

## 2. 适用场景

### 2.1 标签配置场景

- 用于表单、表格或详情页面中的“标签”字段，为业务对象选择已有标签或直接输入创建新标签。
- 常见于设备、策略、规则等配置表单，也可出现在详情页编辑区或列表快捷编辑入口。
- 标签配置通常是用户使用标签的主要入口，重点是选择已有标签、搜索标签、创建新标签和绑定到当前对象。

### 2.2 标签管理场景

- 用于资产标签、用户标签、事件标签、策略标签、数据标签、自定义标签、批量打标和标签筛选等需求。
- 当标签管理只是主页面中的辅助能力时，优先设计为按钮入口触发的弹窗，不单独拆为独立菜单页面。
- 当标签涉及复杂分类、权限、颜色体系、关联对象详情或审计日志时，再扩展为独立页面、抽屉详情或多Tab结构。
- 标签管理通常作为“标签管理”按钮入口出现，用于集中查看所有标签及其引用次数。

### 2.3 数据联动关系

- 标签管理是所有标签的汇总维护入口；标签配置是业务对象绑定标签的主要使用入口。
- 标签管理中新增的标签应出现在标签配置选择框的候选列表中。
- 标签配置中直接创建的新标签应自动选中，并同步出现在标签管理列表中。
- 标签配置为对象绑定或移除标签后，标签管理中的被引用次数应随之变化。
- 删除标签时要结合引用次数判断是否允许删除、是否需要二次确认或提示影响范围。
- 如果页面同时提供标签配置和标签管理入口，HTML页面内容区需要说明两者共享同一份标签数据源。

## 3. 场景一：标签管理

### 3.1 常见页面组合

| 页面 | 页面类型 | 用途 | 常见入口 |
|---|---|---|---|
| 标签管理 | 弹窗列表页 | 对标签进行新增、单条删除、批量删除和引用次数查看 | 主页面工具栏按钮“标签管理” |
| 新增标签 | 气泡窗表单 | 输入标签名称并新增到标签列表首行 | 标签管理弹窗内“新增”按钮 |
| 删除确认 | 二次确认气泡窗 | 确认单条删除或批量删除，避免误操作 | 操作列“删除”或弹窗工具栏“删除”按钮 |

### 3.2 标签管理弹窗

线框图：

```text
点击“标签管理”按钮后弹出 640px 宽弹窗

┌────────────────────────────────────────────────────────────────┐
│ 标签管理                                                   ×    │
├────────────────────────────────────────────────────────────────┤
│                                                                │
│  [新增]  [删除]                                                │
│                                                                │
│  ┌──────┬──────────────────────────────┬────────────┬────────┐ │
│  │  ☐   │ 标签名称                     │ 被引用次数 │ 操作   │ │
│  ├──────┼──────────────────────────────┼────────────┼────────┤ │
│  │  ☐   │ 标签A                        │ 3          │ 删除   │ │
│  │  ☐   │ 标签B                        │ 0          │ 删除   │ │
│  │  ☐   │ 标签名称较长时单行省略...    │ 12         │ 删除   │ │
│  └──────┴──────────────────────────────┴────────────┴────────┘ │
│                                                                │
├────────────────────────────────────────────────────────────────┤
│                                                   [关闭]       │
└────────────────────────────────────────────────────────────────┘
```

- 页面类型：按钮触发的弹窗列表页。
- 入口形式：在所属业务页面提供“标签管理”按钮，点击后打开标签管理弹窗。
- 弹窗标题：标签管理。
- 弹窗宽度：640px。
- 弹窗圆角：4px，遵循统一弹窗圆角。
- 弹窗底部：仅保留“关闭”按钮，使用普通按钮，右对齐；不提供“确定”“保存”等提交型底部按钮。
- 页面区块：顶部操作区、标签表格、底部关闭按钮。
- 顶部操作区：位于表格左上方，包含“新增”和“删除”两个按钮，横向排列，按钮间距8px，按钮高度32px。
- 顶部按钮：
  - 新增：主按钮，点击后弹出新增标签气泡窗。
  - 删除：普通按钮，未勾选表格数据时禁用；勾选至少1条后激活，点击后弹出批量删除确认气泡窗。
- 表格字段顺序：多选列、标签名称、被引用次数、操作。
- 表格字段说明：
  - 多选列：复选框，用于批量选择标签。
  - 标签名称：文字展示标签名称。
  - 被引用次数：数字展示该标签被引用次数，新增标签默认展示0。
  - 操作：提供“删除”操作按钮。
- 关键交互：
  1. 点击“标签管理”按钮后，打开标签管理弹窗。
  2. 勾选表格中至少1条数据后，顶部“删除”按钮从禁用态变为可用态。
  3. 点击弹窗底部“关闭”按钮后，关闭弹窗；弹窗内未提交的气泡窗状态应随弹窗关闭而清理。
- 数据联动：
  - 标签管理弹窗展示的标签数据与标签配置选择框候选数据一致。
  - 在标签管理中新增标签后，该标签应进入标签配置选择框候选列表。
  - 标签配置中创建的新标签应同步显示在标签管理表格中。
  - 被引用次数应根据业务对象绑定标签的数量变化。
- 状态与边界：
  - 标签列表为空时，表格展示空状态，顶部“新增”仍可用，“删除”保持禁用。
  - 被引用次数为0时展示数字0，不展示空值。
  - 标签名称过长时单行省略并支持悬浮查看完整名称，避免撑开弹窗。
  - 删除按钮状态必须与勾选状态联动，批量删除完成后清空勾选状态。

### 3.3 新增标签

- 页面类型：由“新增”按钮触发的气泡窗表单。
- 容器形式：Popover，贴近“新增”按钮展示。
- 气泡窗内容：标签名称输入框、底部按钮组。
- 输入框：高度32px，Placeholder为“请输入标签名称”。
- 按钮组：右对齐，包含“取消”和“确定”两个按钮，按钮间距8px。
- 按钮样式：取消为普通按钮，确定为主按钮。
- 提交行为：
  1. 用户输入标签名称后点击“确定”。
  2. 气泡窗关闭。
  3. 新标签插入表格第一行。
  4. 新标签的“被引用次数”默认为0。
  5. 新标签同步进入标签配置选择框候选列表。
- 取消行为：点击“取消”关闭气泡窗，不新增数据。
- 状态与边界：
  - 输入为空时不应新增标签，可保持确定按钮禁用或给出轻量校验提示。
  - 标签名称前后空格应在提交时清理。
  - 如业务要求标签唯一，应在提交时校验重名并给出提示；未明确时作为待确认问题。

### 3.4 单条删除

- 页面类型：操作列触发的二次确认气泡窗。
- 触发入口：点击表格操作列的“删除”按钮。
- 确认文案：确定删除该标签吗？
- 按钮组合：取消为普通按钮，确定为主按钮。
- 确认行为：删除当前行标签，关闭确认气泡窗。
- 取消行为：关闭确认气泡窗，不删除标签。
- 状态与边界：
  - 删除被引用次数大于0的标签时，如业务未说明是否允许删除，应作为待确认问题；默认仅按确认气泡窗完成删除交互，不额外增加强拦截。
  - 删除后表格数据实时刷新；若删除后列表为空，展示空状态。
  - 删除标签后，标签配置选择框候选列表应同步移除该标签；如果该标签已被业务对象绑定，需要按业务规则确认是否解除绑定或阻止删除。

### 3.5 批量删除

- 页面类型：顶部批量操作触发的二次确认气泡窗。
- 触发条件：勾选表格中至少1条数据后，“删除”按钮变为可用。
- 触发入口：点击激活后的顶部“删除”按钮。
- 确认文案：确定删除所选 XX 个标签吗？其中XX为当前已勾选标签数量。
- 按钮组合：取消为普通按钮，确定为主按钮。
- 确认行为：删除所有已勾选标签，清空勾选状态，关闭确认气泡窗。
- 取消行为：关闭确认气泡窗，保留当前勾选状态。
- 状态与边界：
  - 批量删除确认文案中的数量必须与实时勾选数量一致。
  - 批量删除完成后，如果当前页无数据，应展示空状态并保持“删除”按钮禁用。
  - 批量删除后，标签配置选择框候选列表应同步移除被删除标签。

### 3.6 标签管理交互流程

```text
点击“标签管理”按钮
  └─ 打开标签管理弹窗
       ├─ 点击“新增”
       │    └─ 打开新增标签气泡窗
       │         ├─ 输入标签名称并点击“确定” → 关闭气泡窗，表格首行新增标签，引用次数为0，并同步成为标签配置候选项
       │         └─ 点击“取消” → 关闭气泡窗，不新增数据
       │
       ├─ 勾选标签数据 → 顶部“删除”按钮激活
       │    └─ 点击顶部“删除”
       │         └─ 打开确认气泡窗：“确定删除所选 XX 个标签吗？”
       │              ├─ 点击“确定” → 批量删除，清空勾选状态，关闭气泡窗，并同步更新标签配置候选项
       │              └─ 点击“取消” → 关闭气泡窗，保留勾选状态
       │
       ├─ 点击操作列“删除”
       │    └─ 打开确认气泡窗：“确定删除该标签吗？”
       │         ├─ 点击“确定” → 删除该条标签，关闭气泡窗，并同步更新标签配置候选项
       │         └─ 点击“取消” → 关闭气泡窗，不删除标签
       │
       └─ 点击“关闭” → 关闭标签管理弹窗
```

## 4. 场景二：标签配置

### 4.1 场景说明

用于为对象选择或新建标签，常见于设备、策略、规则等配置表单。选择框同时支持从已有标签中多选和直接输入创建新标签。标签配置中出现的已有标签来自统一标签数据源，通常与“标签管理”弹窗中的标签列表保持一致。

### 4.2 表单字段规范

- Label 文案：标签。
- 控件类型：多选选择框，支持搜索输入。
- 控件高度：32px（无选中项时）；选中项后高度自适应。
- 控件宽度：填满控件区域。
- Placeholder：默认提示文案为“请选择或直接输入创建新标签”。
- Placeholder隐藏规则：选中至少1个标签后，Placeholder隐藏。

### 4.3 控件结构

单个多选选择框：

```text
┌──────────────────────────────────────────────────┐
│ [标签A ×]  [标签B ×]  请选择或直接输入创建新标签  ▼ │
└──────────────────────────────────────────────────┘
```

### 4.4 下拉面板行为

#### 无输入时

展示所有已有标签列表，可多选勾选。

#### 输入过程中

- 实时模糊匹配已有标签数据，仅展示匹配结果。
- 面板最后一行始终展示创建提示行：“创建标签：xxx”（xxx 为当前输入内容）。

```text
┌──────────────────────────────┐
│ ☐ 标签A                      │  ← 匹配结果
│ ☐ 标签AB                     │  ← 匹配结果
│ ──────────────────────────── │
│ + 创建标签：标签ABC            │  ← 创建提示行
└──────────────────────────────┘
```

#### 无匹配结果时

- 已有标签列表区域为空。
- 创建提示行仍然展示：“创建标签：xxx”。

```text
┌──────────────────────────────┐
│                              │  ← 无匹配项
│ + 创建标签：新标签             │  ← 创建提示行始终存在
└──────────────────────────────┘
```

### 4.5 创建标签方式

| 方式 | 操作 | 结果 |
|------|------|------|
| 回车键 | 输入内容后按回车 | 以当前输入内容创建新标签，自动选中，添加到已选区域 |
| 点击创建提示行 | 点击面板最后一行“创建标签：xxx” | 以 xxx 创建新标签，自动选中，添加到已选区域 |

### 4.6 创建行为规则

- 创建的新标签自动选中，以 Tag 形式展示在选择框内。
- 创建后输入框清空，面板刷新（新标签出现在已有列表中）。
- 创建后的新标签同步进入标签管理列表，引用次数按当前绑定对象更新。
- 如果输入内容与已有标签完全一致，不得重复创建，应直接选中该已有标签。
- 创建提示行仅在输入内容不为空时展示；输入为空时隐藏。

### 4.7 创建提示行样式

| 属性 | 规范 |
|------|------|
| 位置 | 面板最后一行，与匹配结果之间有分割线 |
| 文案格式 | “创建标签：xxx” |
| 图标 | 前置“+”图标 |
| hover | 有 hover 态背景 |
| 点击 | 触发创建 |

## 5. Coding提示

### 5.1 标签管理 Coding提示

- 推荐复用组件：Button、Modal、Table、Checkbox、Popover、Popconfirm、Input。
- 弹窗实现：标签管理使用Modal，宽度固定640px，footer仅渲染一个右对齐的普通“关闭”按钮。
- 表格实现：使用受控selectedRowKeys或等价状态管理多选；顶部“删除”按钮disabled状态由选中数量决定。
- 新增实现：新增气泡窗使用受控open状态和受控输入值；确认后将新标签插入数据源第一项，并设置引用次数为0。
- 删除实现：单条删除按当前行id过滤数据；批量删除按选中id集合过滤数据，并在确认后清空选中状态。
- 数据源联动：标签管理列表与标签配置选择框候选项应来自同一份标签数据源；新增、删除标签后需要同步更新候选项。
- Mock数据要求：至少覆盖3类数据：引用次数大于0、引用次数为0、标签名称较长；批量选择和空列表状态必须可演示。
- 状态联动：新增、单条删除、批量删除后，表格数据、勾选状态、按钮禁用态、空状态和标签配置候选项要同步更新。
- 待确认问题：如果业务未明确是否允许删除已被引用标签，应询问“被引用次数大于0的标签是否允许删除，是否需要强拦截或提示影响范围”。

### 5.2 标签配置 Coding提示

- 推荐复用组件：Select 或支持 tags/multiple 模式的多选选择框。
- 选择框实现：选择框为多选模式，高度32px（无选中项时）；选中项后高度自适应。
- 搜索匹配实现：输入过程中实时模糊匹配已有标签数据。
- 新建标签实现：按回车键或点击“创建标签：xxx”行创建新标签，创建后自动选中并清空输入框。
- 去重实现：输入内容与已有标签完全一致时不重复创建，直接选中已有标签。
- 数据源联动：标签配置候选项与标签管理列表使用同一份标签数据；标签配置中新建的标签应同步进入标签管理列表。
- Mock数据要求：至少包含已有标签列表、匹配结果、无匹配结果和新建标签后的列表更新。
- 状态联动：新建标签后，该标签出现在已有标签列表和标签管理列表中，并以Tag形式展示在选择框内。
