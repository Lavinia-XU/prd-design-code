# 策略管理主题设计模板

## 适用场景
- 用于配置和管理需要创建多条“满足指定条件后执行对应动作”的业务规则。
- 适用于企业安全策略、审计管控策略等场景。
- 常见需求表达包括策略、访问控制、路由策略、防火墙策略、检测策略、处置策略等。
- 核心目标是将多条业务规则抽象为：
  - 规则条件：什么情况下触发策略。
  - 执行动作：匹配后系统做什么。
  - 生效范围：策略影响哪些对象。
- 常见业务流程：管理员创建策略 → 配置规则条件 → 设置执行范围 → 启用策略 → 系统根据条件自动执行动作。
- 策略通常具备优先级概念，用于解决多个策略同时匹配时的执行顺序问题。

## 常见页面组合
| 页面ID | 页面名称 | 页面类型 | 页面用途 | 入口方式 | 关键交互 | 设计来源 |
|---|---|---|---|---|---|---|
| P001 | 策略列表页 | 基础表格页 | 查看、筛选、排序、管理已有策略 | 独立菜单入口 | 点击新增或编辑按钮打开P002；点击策略名称打开P002并带入已有数据；点击明细数字或对象标签可按需打开抽屉详情 | 通用设计 |
| P002 | 新增/编辑策略页 | 弹窗表单页 | 创建、编辑或查看策略规则 | 列表页新增按钮、编辑按钮、策略名称链接 | 新增为空数据，编辑和查看带入已有数据；无编辑权限或默认策略场景下字段禁用；点击确定、取消或关闭按钮返回P001 | 通用设计 |

### 页面组合说明
- 新增、编辑、查看通常使用同一个页面：新增时表单为空数据，编辑时带入已有数据；一般不单独设计“查看”按钮，用户点击策略名称后打开编辑页面并带入已有数据来完成查看需求；当用户没有编辑权限或策略不允许编辑时，页面字段禁用且不可修改。
- 部分信息允许按需补充独立抽屉详情页：例如策略关联规则组在表格中只展示数量，点击数量后打开抽屉查看具体规则组；生效对象为对象组时，点击生效对象后打开抽屉查看实际生效对象列表。是否补充抽屉详情页，按需求中是否需要查看明细决定。
- 策略通常存在一条默认策略：默认策略只能查看，不能编辑和删除；默认策略永远固定在表格最后。

## 推荐页面层级
```text
策略管理
  新增/编辑策略
```

## 页面设计要点

### P001-策略列表页
- 页面类型：基础表格页。
- 页面目标：让管理员集中查看策略、定位目标策略、批量管理状态并调整执行优先级。
- 页面内容区块：只有一个表格，左上方是按钮区，右上方是筛选搜索区。

#### 按钮区
| 名称 | 用途 | 交互说明 |
|---|---|---|
| 新增 | 创建新的策略 | 点击后打开新增/编辑策略弹窗。 |
| 删除 | 用于批量删除 | 需要勾选至少一个对象后激活按钮；点击删除后弹出二次确认，告知删除风险；确认后删除所选策略。 |
| 启用 | 用于批量启用策略 | 需要勾选至少一个对象后激活按钮；点击启用后需要二次确认，告知会立即生效；策略状态从禁用切换为启用，已经启用的策略跳过。 |
| 禁用 | 用于批量禁用策略 | 需要勾选至少一个对象后激活按钮；点击禁用后策略不再生效；策略状态从启用切换为禁用，已经禁用的策略跳过。 |
| 移动 | 用于批量调整策略优先级 | 点击后打开弹窗；优先级位置选择方式参考 [优先级配置主题设计模板](../03-function-patterns/priority-configuration.md)；提交后按照选择把所选对象移动到目标策略之前或之后。 |
| 导入 | 用于批量导入策略 | 交互方式参考 [导入功能点设计模板](../03-function-patterns/import.md)，结合策略字段、规则条件、执行动作和生效范围定义模板与校验规则。 |
| 导出 | 用于批量导出策略 | 交互方式参考 [导出功能点设计模板](../03-function-patterns/export.md)，支持按全部策略、当前筛选结果或勾选策略导出。 |

#### 筛选搜索区
- 常见筛选项：策略名称、状态、生效对象、创建人、生效时间、更新时间、规则类型或业务对象类型。
- 搜索建议：优先支持按策略名称关键字搜索；搜索无结果时展示无结果空状态，并保留重置入口。
- 筛选联动：状态筛选应与启用、禁用操作后的列表状态同步更新。

#### 表格区
| 字段 | 展示形式 | 说明 |
|---|---|---|
| 优先级 | 数字/排序序号 | 决定策略执行顺序，支持调整。 |
| 策略名称 | 链接文本 | 唯一标识策略，可进入详情或打开编辑视图。 |
| 描述 | 文本 | 补充策略用途。 |
| 规则相关字段 | 文本/标签 | 根据实际策略规则内容补充，例如规则类型、匹配条件、动作类型、风险等级等。 |
| 生效对象 | 标签/文本 | 展示组织、用户、设备、资产、地址等范围。 |
| 生效时间 | 时间范围 | 展示策略有效周期，例如全天、上班时间、自定义时间段。 |
| 状态 | 状态标签 | 启用、禁用。 |
| 创建人 | 文本 | 创建者信息。 |
| 创建时间 | 时间 | 策略创建时间。 |
| 更新时间 | 时间 | 最近一次更新时间。 |
| 操作 | 操作按钮 | 编辑、删除、复制等；一般不单独提供查看按钮，查看通过点击策略名称进入；默认策略不展示编辑和删除。 |

#### 关键交互
- 新增：点击后打开P002新增弹窗；保存成功后关闭弹窗并刷新列表，新策略按默认优先级规则插入列表。
- 编辑：点击行内编辑后打开P002编辑弹窗；保存成功后关闭弹窗并刷新该行内容。
- 查看：一般不单独提供查看按钮；点击策略名称后打开P002并带入已有数据来完成查看需求；如果用户没有编辑权限或策略不允许编辑，P002内字段禁用且不可修改；点击可查看的明细字段时，可按需打开独立抽屉详情。
- 删除：单行删除和批量删除都必须二次确认；确认文案需提示删除后策略不再生效；默认策略不允许删除。
- 复制：复制当前策略规则、执行动作和生效范围，生成一条新策略；复制后的策略名称默认为“原策略名称-副本”。
- 启用/禁用：操作前提示状态影响；操作成功后状态标签即时切换，并刷新筛选结果。
- 调整优先级：新增表单中的优先级配置和移动弹窗中的位置选择均参考 [优先级配置主题设计模板](../03-function-patterns/priority-configuration.md)；优先级变化后表格顺序和优先级序号同步更新；当多个策略同时匹配时，按优先级高低执行。

#### 状态与边界
- 未选择任何策略时，批量删除、批量启用、批量禁用、移动按钮置灰或点击后提示“请先选择策略”。
- 空列表时展示创建引导，保留新增入口。
- 搜索无结果时展示无结果提示，保留重置筛选入口。
- 启用策略时，如果规则条件、执行动作或生效范围不完整，应提示无法启用并引导编辑补全。
- 删除、禁用、移动等操作失败时，保留当前列表状态并给出失败原因。
- 长策略名称、长描述、生效对象过多时使用省略、气泡或折叠标签展示。
- 默认策略固定在表格最后，不参与移动排序，不允许编辑和删除；点击策略名称后打开P002，字段禁用且不可修改。

### P002-新增/编辑策略页
- 页面类型：弹窗表单页。
- 页面目标：创建新的策略规则，或编辑已有策略的条件、动作、生效范围和状态；没有编辑权限或策略不允许编辑时，用同一页面承载查看需求。
- 入口方式：从P001策略列表页的新增按钮、编辑按钮、策略名称链接进入。
- 返回方式：点击确定、取消或关闭按钮返回P001。

#### 表单区
| 字段 | 展示形式 | 说明 |
|---|---|---|
| 策略名称 | 输入框 | 必填；用于唯一标识策略，需校验重名。 |
| 描述 | 文本域 | 非必填；说明策略用途、适用对象或业务背景。 |
| 优先级 | 数字/位置选择 | 可选；用于决定多个策略同时匹配时的执行顺序；位置选择方式参考 [优先级配置主题设计模板](../03-function-patterns/priority-configuration.md)。 |
| 状态 | 开关/单选 | 启用或禁用；新增时可默认禁用，避免未配置完成即生效。 |
| 业务实际的规则配置 | 条件配置器/表单组/业务组件 | 根据具体业务定义规则字段，用于配置匹配对象、匹配条件、规则参数或条件组合。 |
| 执行动作 | 下拉框/单选/配置表单 | 定义匹配后做什么，例如允许、阻断、告警、隔离、审批、通知、打标等。 |
| 生效时间 | 时间范围选择器 | 定义策略有效周期，例如全天、工作日、指定时间段。 |
| 生效范围 | 组织/对象选择器 | 定义影响哪些对象，支持组织、用户、用户组、设备组、资产组等范围。 |

#### 底部操作
- 确定：校验必填项、重名、条件完整性、动作完整性和生效范围；校验通过后保存并返回P001。
- 取消：未修改时直接关闭；已修改时提示未保存内容。
- 关闭：逻辑同取消。

#### 状态与边界
- 策略名称为空、重名或超过长度限制时，需要给出字段级错误。
- 匹配条件为空、条件组合不合法、动作未选择或生效范围为空时，不允许保存或不允许启用。
- 编辑已启用策略时，如果修改会立即影响线上策略，点击确定前应提示变更风险。
- 条件项过多时，应支持折叠、分组或摘要展示，避免弹窗内容过长。

## Coding提示
- 推荐复用组件：基础表格、批量操作工具栏、搜索筛选、状态标签、二次确认弹窗、弹窗表单、对象选择器、时间范围选择器、条件配置器。
- Mock数据要求：覆盖启用、禁用、不同优先级、长策略名称、长描述、多生效对象、无生效对象、全天与自定义时间、创建时间和更新时间差异等数据。
- 状态联动：新增、编辑、删除、复制、启用、禁用、移动后，列表数据、状态标签、优先级序号、筛选结果和空状态需要同步变化。
- 极端情况：规则冲突、优先级重复、生效对象为空、策略名称重复、已启用策略被编辑、批量操作中部分策略状态不一致、导入数据字段缺失等。
- 导入/导出关联：如需求明确包含导入，读取 [导入功能点设计模板](../03-function-patterns/import.md)，并在页面说明中明确文件选择、模板下载、解析校验、导入结果和失败明细；如需求明确包含导出，读取 [导出功能点设计模板](../03-function-patterns/export.md)，并在页面说明中明确导出范围、导出字段、文件生成和文件下载。
