# 任务管理主题设计模板

## 适用场景
- 用于对指定对象创建立即执行、周期执行或指定时间执行的任务，并持续跟踪任务进展与执行结果。
- 适用于版本包升级、补丁包升级、软件分发、配置分发、合规扫描、安全扫描、资产巡检、终端处置等场景。
- 常见需求表达包括任务管理、升级任务、分发任务、扫描任务、巡检任务、定时执行、周期执行、执行进度、失败重试等。
- 核心目标是将一次或一类任务抽象为：
  - 任务对象：任务作用于哪些用户、设备、终端、资产或对象组。
  - 任务内容：任务具体执行什么，例如升级、分发、扫描、巡检或处置。
  - 执行方式：任务何时执行，例如立即执行、指定时间执行或周期执行。
  - 执行过程：任务当前处于什么状态，每个对象的执行进展和失败原因是什么。
- 常见业务流程：管理员创建任务 → 配置任务对象和执行方式 → 启用任务 → 系统按规则执行 → 管理员查看整体进度和对象明细 → 对失败对象执行重试或调整任务。
- 任务通常同时具备“启用状态”和“执行状态”：启用状态决定任务是否允许继续触发或运行；执行状态反映任务当前执行生命周期。

## 常见页面组合
| 页面ID | 页面名称 | 页面类型 | 页面用途 | 入口方式 | 关键交互 | 设计来源 |
|---|---|---|---|---|---|---|
| P001 | 任务管理页 | 基础表格页 | 查看、筛选、管理已创建任务，跟踪任务整体进展与结果 | 独立菜单入口 | 点击新增打开P002；点击任务名称或详情打开P003；点击编辑打开P002并带入已有数据；支持复制、删除、启用、禁用和批量操作 | 通用设计 |
| P002 | 新建/编辑任务页 | 表单页/弹窗表单页/抽屉表单页 | 创建任务或编辑任务基础信息、任务对象和执行方式 | 任务管理页新增按钮、编辑按钮 | 根据执行方式动态展示立即执行、周期执行、指定时间执行配置；保存后返回P001 | 通用设计 |
| P003 | 任务详情页 | 抽屉详情页 | 查看任务基本信息、整体进展、对象执行明细和失败重试 | 任务名称链接、详情按钮 | 顶部概览展示任务信息和操作；下方表格展示设备、终端或对象执行状态；支持筛选、批量重试和单对象重试 | 通用设计 |

### 页面组合说明
- 任务管理通常由“列表 + 新建/编辑表单 + 详情抽屉”组成：列表用于管理任务，表单用于配置任务，详情抽屉用于查看执行明细和处理失败对象。
- 新建和编辑通常复用同一个表单：新建时表单为空数据，编辑时带入已有任务数据；执行中的任务不能编辑；单次执行且已经执行完成的任务也不能编辑，只能通过复制生成新任务。
- 任务详情默认使用抽屉详情页承载，适合从列表快速查看任务概览和对象明细，不打断任务列表上下文；如果对象明细字段很多或需要复杂分析，也可扩展为独立详情页。
- 列表中的任务名称和操作列“详情”应打开同一个任务详情页，避免出现多个查看入口但内容不一致。
- 如果需求中包含周期执行配置，尤其是创建任务表单中的“执行周期”字段，周期配置细节优先参考 [执行周期配置功能点模板](../03-function-patterns/execution-cycle.md)，按每天、每周、每月的联动选择框补齐周期类型、补充配置和执行时间。

## 推荐页面层级
```text
任务管理
  新建/编辑任务
  任务详情
```

## 页面设计要点

### P001-任务管理页
- 页面类型：基础表格页。
- 页面目标：让管理员集中查看任务列表、快速识别执行中和异常任务，并完成新增、删除、启用、禁用、查看详情等操作。
- 页面内容区块：表格上方左侧为按钮区，右侧为筛选搜索区，下方为任务表格；状态分段Tab作为筛选搜索区的第一个筛选项展示，不单独占用顶部行。

#### 筛选区首项：状态分段Tab
| 名称 | 展示形式 | 说明 |
|---|---|---|
| 全部 | 文本 + 数量 | 展示全部任务数量，点击后表格不过滤执行状态。 |
| 执行中 | 文本 + 数量 | 展示执行中的任务数量，点击后只展示正在运行的任务。 |
| 执行完成 | 文本 + 数量 | 展示已完成且有明确成功/失败结果的任务数量。 |
| 执行终止 | 文本 + 数量 | 展示被管理员手动终止、已停止继续执行的任务数量。 |

#### 按钮区
| 名称 | 用途 | 交互说明 |
|---|---|---|
| 新增 | 创建新的任务 | 点击后打开P002新建任务页。 |
| 删除 | 用于批量删除任务 | 需要勾选至少一个任务后激活；点击后弹出二次确认，提示删除后无法继续查看或执行该任务；执行中的任务不建议直接删除，可提示先终止或暂停。 |
| 启用 | 用于批量启用任务 | 需要勾选至少一个任务后激活；启用后任务可按配置触发或继续执行，任务状态从任务关闭恢复为待执行或可触发状态；已启用任务跳过。 |
| 禁用 | 用于批量禁用任务 | 需要勾选至少一个任务后激活；禁用后任务不再触发新的执行，对应任务状态为任务关闭；是否影响已进行中的对象需按业务规则说明；已禁用任务跳过。 |

#### 筛选搜索区
- 固定筛选：筛选搜索区的第一个筛选项使用分段式Tab展示不同任务状态数量，至少包含全部、执行中、执行完成、执行终止；该Tab与其他筛选条件同处表格右上方，不单独占用页面顶部区域。
- 常见筛选项：任务名称、任务类型、执行方式、任务状态、启用状态、生效对象、创建人、创建时间、更新时间。
- 搜索建议：优先支持按任务名称关键字搜索；如果业务对象明确，也可支持按设备名称、终端名称、用户名称或对象组名称搜索。
- 筛选形式：普通条件使用选择框 + 搜索框；当筛选和搜索条件超过5个时，改为高级搜索框承载更多条件，避免工具栏过长。
- 筛选联动：状态分段Tab与筛选项中的任务状态应保持一致；启用、禁用、删除、任务完成或任务进度变化后，Tab数量和表格结果需同步刷新。

#### 表格区
| 字段 | 展示形式 | 说明 |
|---|---|---|
| 任务名称 | 链接文本 | 唯一标识任务；点击后打开P003任务详情页。 |
| 任务描述 | 文本 | 补充任务目的、执行内容或适用场景；长文本省略并支持气泡查看。 |
| 生效对象 | 标签/文本/数量链接 | 展示用户、设备、终端、资产或对象组；对象较多时展示摘要和数量。 |
| 任务类型 | 标签/文本 | 例如版本包升级、补丁包升级、软件分发、配置分发、扫描、巡检等。 |
| 执行方式 | 文本/标签 | 例如立即执行、单次执行、指定时间执行、每周三5点、每天2点等。 |
| 任务状态 | 图标标签 + 进度条 | 展示待执行、执行中、执行完成、执行终止、执行暂停、任务关闭；执行中状态建议增加进度条展示整体进展。 |
| 任务结果 | 数字组合/链接 | 展示成功数量和失败数量，例如成功120、失败3；点击失败数量可打开P003并筛选失败对象。 |
| 启用状态 | 状态标签/开关 | 展示启用或禁用；如果使用开关，切换前需确认对执行的影响。 |
| 创建人 | 文本 | 展示任务创建者。 |
| 创建时间 | 时间 | 展示任务创建时间。 |
| 更新时间 | 时间 | 展示任务最近更新时间或最近执行进展更新时间。 |
| 操作 | 操作按钮 | 详情、编辑、复制、删除；执行中任务不允许编辑；单次执行且已执行完成的任务不允许编辑，仅提供复制入口；删除需按业务限制置灰或提示风险。 |

#### 任务状态与对应操作
| 任务状态 | 解释 | 对应的操作 |
|---|---|---|
| 待执行 | 任务已创建并启用，但尚未到达执行时间或尚未开始下发。 | 编辑、复制、删除、禁用；如果业务允许手动提前处理，可提供立即执行。 |
| 执行中 | 任务正在下发或对象正在执行中，需要展示整体进度。 | 详情、终止；如果该任务支持暂停和继续，提供暂停；执行中任务不能编辑。 |
| 执行暂停 | 任务执行过程中被手动暂停，暂时不继续下发或执行，保留当前进度。 | 继续、终止、详情；点击继续后任务回到执行中。 |
| 执行完成 | 任务已执行完成，包含全部成功或部分失败但流程已结束的情况。 | 详情、复制、删除；单次执行且已完成的任务不能编辑，只能复制。 |
| 执行终止 | 任务执行中被管理员手动终止，系统不再继续执行剩余对象。 | 详情、复制、删除；终止后的任务通常不能继续执行。 |
| 任务关闭 | 任务被禁用后进入关闭状态，不再触发新的执行。 | 启用、详情、复制、删除；点击启用后按任务配置恢复到待执行或可触发状态。 |

#### 关键交互
- 新增：点击后打开P002；保存成功后返回P001，新任务出现在列表中；如果选择立即执行且启用，任务状态可从待执行快速进入执行中。
- 编辑：点击行内编辑后打开P002并带入已有数据；执行中的任务不能编辑，编辑入口置灰或点击后提示“执行中的任务不能编辑”；单次执行且已经执行完成的任务不能编辑，列表中不展示编辑或将编辑置灰，并引导用户使用复制。
- 复制：点击复制后基于当前任务生成一条新任务，并打开P002或直接生成草稿；任务名称自动追加“-副本”；默认保留原任务的任务类型、任务内容配置、生效对象、执行方式、启用状态等配置；如果原任务为指定时间执行，需要清除具体开始时间和结束时间，让用户重新选择时间，避免复制后沿用已过期或冲突的时间窗口。
- 查看详情：点击任务名称或详情按钮打开P003；如果从失败数量进入，应自动筛选失败对象。
- 删除：单行删除和批量删除都需要二次确认；执行中任务删除前应提示可能中断任务或影响结果留存。
- 终止：对进行中的任务提供终止操作；点击终止后二次确认，确认后手动停止任务，任务状态变为执行终止，并停止继续下发或执行剩余对象。
- 暂停/继续：如果任务支持暂停后继续，对执行中的任务提供暂停操作，点击后任务状态变为执行暂停；对执行暂停的任务提供继续操作，点击后任务状态回到执行中并延续原进度。
- 启用/禁用：操作前提示状态影响；禁用后任务不再触发新的执行，任务状态变为任务关闭；启用后按任务配置恢复为待执行或可触发状态；操作成功后状态标签、Tab数量和筛选结果同步更新。
- 状态查看：执行中任务在状态标签旁展示进度条；进度条可显示百分比或“已完成对象数/总对象数”。

#### 状态与边界
- 未选择任何任务时，批量删除、启用、禁用按钮置灰或点击后提示“请先选择任务”。
- 空列表时展示创建引导，保留新增入口。
- 搜索无结果时展示无结果提示，保留重置筛选入口。
- 执行中任务如果进度为0，需要明确展示“0%”或“0/总数”，避免被误解为无数据。
- 任务状态与启用状态需要保持联动但避免混淆：禁用任务对应任务关闭，不等同于执行失败；执行暂停表示任务可继续，不等同于任务关闭；执行终止表示任务被手动停止，通常不能继续执行。
- 成功数和失败数都为0时，需要结合任务状态判断展示为“暂无结果”或“0”。
- 生效对象为空、任务配置不完整或执行方式缺失时，不允许启用或执行。
- 长任务名称、长描述、生效对象过多时使用省略、气泡、折叠标签或数量链接展示。

### P002-新建/编辑任务页
- 页面类型：表单页、弹窗表单页或抽屉表单页；字段较少时可用弹窗，配置较多或对象选择复杂时建议用抽屉或独立表单页。
- 页面目标：配置任务基础信息、生效对象、执行方式和启用状态，确保任务能够按预期执行。
- 入口方式：从P001任务管理页的新增按钮或编辑按钮进入。
- 返回方式：点击确定或取消按钮返回P001。

#### 表单区
| 字段 | 展示形式 | 说明 |
|---|---|---|
| 任务名称 | 输入框 | 必填；用于唯一标识任务，需校验重名和长度。 |
| 描述 | 文本域 | 非必填；说明任务目的、执行内容、影响范围或注意事项。 |
| 状态 | 开关/单选 | 启用或禁用；新增时可默认启用或默认禁用，取决于是否允许保存后立即触发。 |
| 生效对象 | 用户选择器/设备选择器/终端选择器/资产选择器 | 必填；根据业务对象选择对应选择器，支持按组织、对象组或单个对象选择。 |
| 任务类型 | 下拉框/单选/卡片 | 根据业务选择，例如版本包升级、补丁包升级、软件分发、配置分发、扫描等。 |
| 任务内容配置 | 表单组/上传控件/选择器 | 根据任务类型补充具体配置，例如升级包、补丁包、扫描策略、分发内容或执行参数。 |
| 执行方式 | 卡片单选 | 必填；常见选项为立即执行、周期执行、指定时间执行。 |
| 执行周期 | 周期配置组件 | 选择周期执行后展示；配置方式参考 [执行周期配置功能点模板](../03-function-patterns/execution-cycle.md)，默认由周期类型、补充配置和执行时间组成。 |
| 开始时间 | 时间选择器/单选 + 时间选择器 | 选择指定时间执行后展示；可选择立即开始或选择具体开始时间。 |
| 结束时间 | 时间选择器/单选 + 时间选择器 | 选择指定时间执行后展示；可选择不指定结束时间或选择具体结束时间。 |

#### 执行方式配置
| 执行方式 | 展示与交互 | 适用说明 |
|---|---|---|
| 立即执行 | 选择卡片后不再要求配置开始时间；保存并启用后立即进入待执行或执行中 | 适合一次性升级、紧急分发、即时扫描等任务。 |
| 周期执行 | 选择卡片后展示周期配置区；支持每天、每周、每月或自定义周期 | 适合定期扫描、周期巡检、持续分发检查等任务。 |
| 指定时间执行 | 选择卡片后展示开始时间和结束时间；开始时间支持立即开始或具体时间，结束时间支持不指定或具体时间 | 适合在维护窗口、低峰时段或指定时间范围内执行的任务。 |

#### 底部操作
- 确定：校验任务名称、生效对象、任务类型、任务内容配置、执行方式和时间配置；校验通过后保存并返回P001。
- 取消：未修改时直接返回P001；已修改时提示未保存内容。

#### 状态与边界
- 任务名称为空、重名或超过长度限制时，需要给出字段级错误。
- 生效对象为空时不允许保存或不允许启用。
- 执行方式为空时不允许保存。
- 选择周期执行但周期配置不完整时，不允许保存。
- 指定时间执行时，结束时间不能早于开始时间；如果开始时间选择立即开始，则结束时间必须晚于当前时间或选择不指定结束时间。
- 立即执行任务如果保存时选择启用，应提示保存后任务将开始执行；如果选择禁用，则任务保存为未触发状态。
- 执行中的任务不能编辑，编辑入口应置灰或点击后提示原因。
- 单次执行且已经执行完成的任务不能编辑，只能复制后生成新任务；复制后的任务名称自动追加“-副本”。
- 复制指定时间执行的任务时，保留任务类型、任务内容配置、生效对象、执行方式等配置，但必须清除具体开始时间和结束时间，并要求用户重新选择。

### P003-任务详情页
- 页面类型：抽屉详情页。
- 页面目标：让管理员查看任务基本信息、整体进展和每个生效对象的执行情况，并对失败对象进行重试。
- 入口方式：从P001任务管理页点击任务名称、详情按钮或任务结果中的失败数量进入。
- 返回方式：关闭抽屉返回P001，并保留列表筛选上下文。

#### 顶部概览卡片
| 信息/操作 | 展示形式 | 说明 |
|---|---|---|
| 任务名称 | 标题文本 | 展示任务名称，必要时展示任务类型标签。 |
| 任务描述 | 文本 | 展示任务目的、执行内容或说明。 |
| 生效对象 | 文本/标签/数量 | 展示对象范围摘要和总数。 |
| 任务类型 | 标签/文本 | 展示版本包升级、补丁包升级、分发、扫描等类型。 |
| 执行方式 | 文本 | 展示立即执行、指定时间、周期规则等。 |
| 任务状态 | 图标标签 + 进度条 | 展示待执行、执行中、执行暂停、执行完成、执行终止、任务关闭；执行中展示整体进度。 |
| 任务结果 | 数字卡片/统计项 | 展示成功数量、失败数量、待开始数量、进行中数量。 |
| 启用状态 | 状态标签/开关 | 展示启用或禁用。 |
| 任务操作 | 按钮组 | 根据状态展示编辑、暂停、继续、终止、启用、禁用、删除等操作；高风险操作需要二次确认。 |

#### 对象执行明细区
- 展示具体生效对象的执行情况，例如设备列表、终端列表、用户列表或资产列表。
- 表格上方提供批量重试按钮和高级搜索框；高级搜索框用于搜索对象并筛选任务状态。

| 字段 | 展示形式 | 说明 |
|---|---|---|
| 对象名称 | 链接/文本 | 展示设备名称、终端名称、用户名称或资产名称。 |
| 对象基础信息 | 文本/多字段 | 根据业务展示IP、所属组织、操作系统、版本号、负责人、最近在线时间等。 |
| 任务状态 | 图标标签 | 展示待开始、进行中、成功、失败。 |
| 进度 | 进度条/百分比 | 可选；当单对象执行过程较长时展示。 |
| 失败原因 | 文本 | 失败时展示具体原因；非失败状态展示“-”。 |
| 最近更新时间 | 时间 | 展示该对象状态最近更新时间。 |
| 操作 | 操作按钮 | 默认提供重试；仅失败对象可点击，其他状态置灰或不展示。 |

#### 明细筛选与批量操作
- 高级搜索框常见条件：对象名称、IP、所属组织、对象状态、失败原因、最近更新时间。
- 批量重试：需要勾选至少一个失败对象后激活；点击后二次确认，确认后只对失败对象重新下发任务。
- 单对象重试：点击失败对象行内“重试”后触发；成功提交后该对象状态可切换为待开始或进行中。
- 从P001失败数量进入P003时，默认筛选失败状态，并在高级搜索框中展示当前筛选条件。

#### 状态与边界
- 无对象明细时展示空状态，并说明当前任务暂无生效对象或对象尚未生成执行记录。
- 搜索无结果时展示无结果提示，保留重置筛选入口。
- 未选择任何失败对象时，批量重试按钮置灰或点击后提示“请先选择失败对象”。
- 勾选对象中包含非失败状态时，批量重试应自动过滤非失败对象，或提示仅失败对象支持重试。
- 失败原因过长时使用省略和气泡展示，支持复制错误信息更佳。
- 任务处于执行终止、执行暂停或任务关闭时，重试是否可用需要按业务规则限制；不可用时展示明确原因。
- 详情抽屉关闭后，P001列表中的任务状态、进度和结果数量应同步刷新。

## Coding提示
- 推荐复用组件：基础表格、状态分段Tab、批量操作工具栏、搜索筛选、高级搜索框、状态标签、图标标签、进度条、二次确认弹窗、表单容器、对象选择器、卡片单选、时间选择器、时间范围选择器、抽屉详情页。
- Mock数据要求：覆盖立即执行、周期执行、指定时间执行；覆盖版本包升级、补丁包升级、分发、扫描等任务类型；覆盖待执行、执行中、执行暂停、执行完成、执行终止、任务关闭；覆盖启用、禁用、终止、暂停、继续；覆盖成功数、失败数、0进度、100%进度、部分失败、全部失败、无对象明细、执行中不可编辑、单次执行已完成只能复制、复制指定时间任务需重新选择时间等数据。
- 状态联动：新增、编辑、复制、删除、启用、禁用、终止、暂停、继续、任务执行进度变化、任务完成、单对象重试、批量重试后，列表状态、Tab数量、进度条、任务结果、对象明细状态和筛选结果需要同步变化。
- 表单联动：执行方式使用卡片单选；选择立即执行时隐藏时间配置，选择周期执行时展示周期配置，选择指定时间执行时展示开始时间和结束时间配置。
- 极端情况：任务名称重复、生效对象为空、对象离线、升级包不存在、任务内容配置缺失、时间范围不合法、周期配置不完整、执行中任务被编辑、单次执行已完成任务被编辑、复制任务名称重复、复制指定时间任务未重新选择时间、批量操作部分成功、失败原因过长、重试后再次失败等。
- 执行周期配置关联：如需求涉及周期执行，读取 [执行周期配置功能点模板](../03-function-patterns/execution-cycle.md)，并在创建任务表单说明中明确每天/每周/每月的选择框联动、补充配置、执行时间、宽度分配和校验规则。
