## 使用说明

- 仅作为缺少业务设计Skill或业务设计Skill未覆盖导航时的导航归属参考。
- 不覆盖用户明确输入、业务设计Skill和已有代码；已有代码存在菜单配置时，以代码中的菜单配置为准。
- 本文只辅助判断导航归属、菜单层级、导航结构位置、菜单命名风格和已知菜单Key，不决定页面类型、字段配置、交互组件、功能点细节或Coding实现方式。
- 使用本文给DR新增页面命名时，必须参考DR已有导航命名规律：常用“管理、中心、列表、设置、配置、日志”等词尾，优先表达业务对象，再表达页面用途。
- 新增页面如果放入同一导航菜单或同一父级菜单下，不得与已有菜单或页面重名；如果作为Tab页面，一般也不得与同一页面内其他Tab重名。
- 相同名称仅在不同菜单路径下承载同类任务或对象管理时允许，例如不同菜单下都存在“任务管理”类页面，但页面总览、导航结构和Coding计划中必须写清完整导航路径。
- 当前文档只包含菜单结构，暂未补充Tab页面；如果需求需要判断Tab归属，应列入待确认问题或结合业务设计Skill、已有代码判断。
- 如果不确定需求是否命中DR导航，应作为待确认问题。

## 产品范围

- DR用于深信服下一代端点安全相关场景，覆盖安全监控、检测响应、病毒查杀、隔离区管理、客户端管理、策略中心、任务中心和系统管理等模块。
- 需求涉及终端安全监控、安全事件、告警、日志调查、病毒查杀、隔离区、客户端部署升级、安全策略、IOC、IOA、白名单或系统配置时，可优先参考本文导航。
- 需求只涉及外部处置平台、客户线下流程、后端检测算法、病毒库更新机制或接口同步时，不直接拆为DR导航页面；仅当DR控制台需要提供展示、配置或操作入口时才进入页面设计。

## 导航结构

按一级菜单分段展示完整菜单树；当前未提供分组标题，所有树节点均为导航层级。叶子菜单是可进入页面的导航位置；非叶子节点只作为上级菜单，不直接承载页面，除非用户、业务设计Skill或已有代码明确说明可进入。

```text
DR 下一代端点安全
├─ 安全监控
├─ 检测响应
│  ├─ 安全事件
│  ├─ 告警项
│  └─ 日志调查
├─ 病毒查杀
│  ├─ 病毒态势分析
│  └─ 病毒列表
├─ 隔离区管理
│  ├─ 文件隔离区
│  └─ 资产隔离区
├─ 客户端管理
│  ├─ 客户端列表
│  ├─ 客户端部署
│  └─ 升级管理
├─ 策略中心
│  ├─ 安全策略
│  ├─ 自定义 IOC
│  ├─ 自定义 IOA
│  └─ 白名单管理
├─ 任务中心
└─ 系统管理
   ├─ 基本配置
   ├─ 授权管理
   ├─ 系统日志
   ├─ 通知设置
   ├─ 日志设置
   └─ 个性配置
```

## 常见需求归属

| 需求关键词/场景 | 建议导航归属 | 说明 |
| --------------- | ------------ | ---- |
| 安全态势、终端安全概览、风险监控 | 安全监控 | 安全监控为叶子节点，若需求涉及进一步下钻页面，应以详情页、抽屉或待确认方式处理。 |
| 安全事件、事件调查、响应处置 | 检测响应 / 安全事件 | 用于安全事件查看、分析、处置和事件详情类需求。 |
| 告警查看、告警分析、告警处理 | 检测响应 / 告警项 | 用于告警项列表、筛选、详情和处理类需求。 |
| 日志调查、事件溯源、日志检索 | 检测响应 / 日志调查 | 用于安全日志调查、检索和分析类需求。 |
| 病毒态势、病毒统计分析 | 病毒查杀 / 病毒态势分析 | 用于病毒查杀整体态势、趋势和统计类需求。 |

| 资产隔离、终端隔离解除 | 隔离区管理 / 资产隔离区 | 用于被隔离资产或终端的集中管理。 |

## 待确认触发

- 需求可能同时归属检测响应、病毒查杀、策略中心、任务中心或系统管理。
- 用户指定导航与本文档菜单结构不一致。
- 需要新增一级菜单、二级菜单、三级菜单或Tab。
- 需要把新页面放入已有导航菜单，但页面名称与同一菜单或同一父级菜单下已有名称重复。
- 需要新增Tab，但当前文档尚未补充Tab结构，或新增Tab名称与同一页面内已有Tab可能重复。
- 相同页面名称出现在不同菜单路径下，但需求没有说明所属完整导航路径。
- 需求需要把功能放在叶子节点菜单下的页面区块、按钮、抽屉或弹窗中，但入口位置不明确。
- 导航索引中没有明确对应位置。
