# XDR导航结构

## 使用说明

- 仅作为缺少业务设计Skill或业务设计Skill未覆盖导航时的导航归属参考。
- 不覆盖用户明确输入、业务设计Skill和已有代码。
- 本文只辅助判断导航归属、菜单层级、菜单命名、分组标题和菜单标签，不决定页面类型、字段配置、交互组件或Coding实现方式。
- 当前导航仅包含菜单结构，Tab页面未补充；若需求涉及Tab，应列入待确认问题。
- 如果不确定需求是否命中XDR导航，应作为待确认问题。

## 产品范围

- XDR用于威胁检测、告警分析、事件调查、响应处置、风险管理、资产管理、云安全、系统配置和应用扩展相关场景。
- 需求涉及安全事件、安全告警、风险主机、日志检索、响应流程、检测任务、资产管理、云风险、安全运营配置等内容时，可优先参考本文导航。

## 常见需求归属

| 需求关键词/场景 | 建议导航归属 | 说明 |
| --------------- | ------------ | ---- |
| 安全监控、值守、报表、大屏 | 安全监控 | 根据具体展示目标选择监控总览、值守总览、报表或大屏。 |
| 安全事件、告警分析、日志调查、日志检索 | 威胁分析 | 事件和告警分析优先归属威胁分析；若需求强调响应处置流程，再考虑威胁响应。 |
| 响应处置、预案、工单、智能对抗 | 威胁响应 | 响应动作、流程工单和预案管理优先归属威胁响应。 |
| 脆弱性、检测任务、风险应用、热点威胁 | 风险管理 | 风险和检测任务类需求优先归属风险管理。 |
| 资产总览、资产管理、业务系统、指纹清点 | 资产中心 | 资产对象、业务系统和资产配置类需求优先归属资产中心。 |
| 云资产、云攻击路径、云风险、云检查策略 | 云安全中心 | 云侧安全能力和云环境对接优先归属云安全中心。 |
| 通用配置、账户权限、通知、授权、安全运营配置 | 配置管理 / 基础配置 | 产品基础配置类需求优先归属配置管理下的基础配置分组。 |
| 系统日志、系统运维 | 配置管理 / 系统监控 | 系统运行与运维类需求优先归属系统监控分组。 |
| 产品接入、级联、云端配置 | 配置管理 / 接入配置 | 接入与级联类需求优先归属接入配置分组。 |
| 开放共享、联动码 | 配置管理 / 开放性 | 开放能力和联动类需求优先归属开放性分组。 |
| 探针、安全GPT检测、0Day威胁追踪、物联网安全、钓鱼演习、等保 | 应用中心 | 扩展应用、检测应用和合规模块优先归属应用中心。 |

- 需求涉及配置管理，但未明确属于基础配置、系统监控、接入配置或开放性。
- 需求需要新增一级菜单、二级菜单或Tab页面。
