# DSP导航结构

## 使用说明

- 仅作为缺少业务设计Skill或业务设计Skill未覆盖导航时的导航归属参考。
- 不覆盖用户明确输入、业务设计Skill和已有代码。
- 本文只辅助判断导航归属、菜单层级、菜单命名、分组标题和已知Tab页面，不决定页面类型、字段配置、交互组件或Coding实现方式。
- 配置管理菜单下的“业务配置”“基础配置”“系统监控”“接入配置”“开放性”为菜单分组小标题，不属于导航层级。
- 员工用数可视、告警规则配置、区域IP配置、账户权限、通知设置、系统运维、产品接入已知存在Tab页面；若需求涉及其他Tab结构且本文未覆盖，应列入待确认问题。
- 如果不确定需求是否命中DSP导航，应作为待确认问题。

## 产品范围

- DSP用于深信服数据安全平台相关场景，覆盖数据资产管理、数据访问可视、数据风险监测、数据调查审计、配置管理、APP中心和消息通知。
- 需求涉及数据资产、应用/API/数据库资产、分类分级、员工用数可视、告警研判、日志检索、安全日志、用户目录配置、产品接入或开放共享时，可优先参考本文导航。

## 常见需求归属

| 需求关键词/场景 | 建议导航归属 | 说明 |
| --------------- | ------------ | ---- |
| 数据资产、应用资产、API资产、数据库资产 | 数据资产管理 / 应用资产、API资产、数据库资产 | 按资产对象类型匹配已有菜单。 |
| 数据分布、数据流向、资产分布可视化 | 数据资产管理 / 数据分布可视 | 用于数据资产分布和可视化查看。 |
| 分类分级、数据识别、分类分级工作台 | 数据资产管理 / 分类分级工作台 | 用于分类分级相关工作台能力。 |
| 员工访问数据、员工用数行为 | 数据访问可视 / 员工用数可视 | 用于员工用数视角的访问可视化；若需要区分概览和清单，使用对应Tab。 |
| 数据安全告警、风险告警、告警处置 | 数据风险监测 / 告警研判 | 用于数据安全告警查看、分析和研判。 |
| 告警规则、风险规则、脆弱性规则、告警白名单 | 数据风险监测 / 告警规则配置 / 对应Tab | 用于配置告警规则；风险规则、脆弱性规则、告警白名单为Tab页面。 |
| 日志检索、调查审计 | 数据调查审计 / 日志检索 | 用于跨日志检索和调查。 |
| 安全日志 | 数据调查审计 / 安全日志 | 用于查看数据安全相关日志。 |
| 用户目录、用户IP、账号提取、区域IP、日志审计 | 配置管理 / 对应业务配置菜单 | 配置管理下的“业务配置”为分组标题，不作为导航层级；区域IP配置包含内网区域、外网区域Tab。 |
| 通用配置、主题、账户权限、通知、授权 | 配置管理 / 对应基础配置菜单 | 配置管理下的“基础配置”为分组标题，不作为导航层级；账户权限和通知设置包含Tab页面。 |
| 系统日志、系统运维 | 配置管理 / 对应系统监控菜单 | 配置管理下的“系统监控”为分组标题，不作为导航层级；系统运维包含系统总览、系统告警、系统巡检、版本信息Tab。 |
| 产品接入 | 配置管理 / 产品接入 / 对应Tab | 产品接入包含自有产品、第三方产品、代理配置Tab。 |
| 开放共享、联动码 | 配置管理 / 开放共享、联动码 | 配置管理下的“开放性”为分组标题，不作为导航层级。 |
| 应用中心、APP扩展 | APP中心 / 应用中心 | 用于应用中心相关能力。 |
| 消息通知 | 消息通知 | 该菜单为一级叶子节点。 |
