# 产品导航索引

## 使用原则

- 仅当用户没有提供业务设计Skill，或业务设计Skill未覆盖导航结构时读取。
- 用户明确指定导航时，以用户输入为准。
- 已有代码中存在菜单配置时，以代码中的菜单配置为准。
- 业务设计Skill中存在产品导航、页面导航结构或页面说明时，以业务设计Skill为准。
- 本索引只辅助判断导航归属、菜单层级、导航结构位置和菜单命名风格，不作为最新产品规范。
- 使用本索引给新页面命名时，必须参考对应产品的已有命名规律；放入同一导航菜单或同一Tab容器时避免重名。相同名称仅在不同菜单路径下承载同类任务或对象管理时允许，并必须保留完整导航路径作为区分。
- 本索引不决定页面类型、字段配置、交互组件、功能点细节或Coding实现方式。
- 若导航索引与用户输入、业务设计Skill、已有代码或需求判断冲突，或新增页面命名存在同级重名风险，应列入待确认问题。

## 读取时机

- 需求需要输出导航结构，但缺少业务设计Skill。
- 业务设计Skill提供了产品说明，但没有覆盖导航结构。
- 用户只描述功能目标，未说明该功能应放在哪个菜单下。
- 需求可能归属多个产品模块，需要用导航索引辅助判断候选归属。
- 需要判断是否新增菜单、放入已有菜单、放入已有页面Tab或作为页面操作入口。

## 单个产品导航文档建议结构

单个产品导航文档统一使用以下结构，避免不同产品文档格式不一致，影响AI判断导航归属。

```markdown
# <产品缩写>导航结构

## 使用说明
- 仅作为缺少业务设计Skill或业务设计Skill未覆盖导航时的导航归属参考。
- 不覆盖用户明确输入、业务设计Skill和已有代码。
- 如果不确定是否命中，应作为待确认问题。

## 产品范围
- <产品主要能力范围>

## 导航结构
按一级菜单分段展示完整菜单树；若存在分组标题，需要在树中标注“分组标题”，并说明分组标题不属于可进入导航层级。

```text
一级菜单
├─ 二级菜单
│  ├─ 三级菜单
│  └─ 二级分组标题（分组标题）
└─ 叶子菜单
```
