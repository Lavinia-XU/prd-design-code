# SASE导航结构

## 使用说明

- 仅作为缺少业务设计Skill或业务设计Skill未覆盖导航时的导航归属参考。
- 不覆盖用户明确输入、业务设计Skill和已有代码。
- 本文只辅助判断导航归属、菜单层级、菜单命名、分组标题和菜单标签，不决定页面类型、字段配置、交互组件或Coding实现方式。
- 当前导航仅包含菜单结构，Tab页面未补充；若需求涉及Tab，应列入待确认问题。
- 如果不确定需求是否命中SASE导航，应作为待确认问题。

## 产品范围

- SASE用于云安全访问服务相关场景，覆盖零信任网络访问、数据防泄密、互联网安全访问、全球加速、身份管理、终端管理、对象管理、日志中心和系统管理。
- 需求涉及云安全接入、访问控制、数据防泄密、互联网安全访问、全球加速、终端管理、对象管理、身份认证或日志审计时，可优先参考本文导航。

## 常见需求归属

| 需求关键词/场景 | 建议导航归属 | 说明 |
| --------------- | ------------ | ---- |
| 首页、用户状态、分支监控 | 概览 | 云安全访问整体监控和状态展示优先归属概览。 |
| 零信任访问、应用管理、安全策略、连接器 | 零信任网络访问 | 零信任访问控制、应用发布、安全策略和连接器相关能力优先归属零信任网络访问。 |
| 数据防泄密概览、数据外发、泄密事件、泄密用户、敏感对象 | 数据防泄密 | 数据安全和泄密风险相关需求按概览、分析、策略分组归属。 |
| 互联网应用管控、应用审计、上网行为、威胁管理 | 互联网安全访问 | 上网安全访问、行为分析、审计和策略类需求优先归属互联网安全访问。 |
| 全球加速、加速节点、加速通道 | 全球加速服务 | 全球加速分析与配置类需求优先归属全球加速服务。 |
| 用户、认证配置、认证策略 | 身份管理 | 身份、用户、认证相关需求优先归属身份管理。 |
| 终端资产、软件管理、终端防病毒、客户端配置 | 终端管理 | 终端对象、软件、客户端部署和终端安全管理优先归属终端管理。 |
| IP地址、时间计划、应用识别库、URL分类库、进程库、文件类型组 | 对象管理 | 平台公共对象和对象库相关需求优先归属对象管理。 |
| 日志、审计、登录、合规、管理员操作 | 日志中心 | 日志类需求根据日志类型选择日志中心下对应分组。 |
