## 1. 适用范围

本规范适用于中后台主列表页、对象管理页、日志/事件/告警列表、配置列表等具备查询、筛选、排序、分页和操作能力的表格。

详情页内嵌表格、弹窗表格、抽屉表格、纯展示型表格、报表型表格可按容器层级和业务复杂度裁剪使用，但仍应遵守状态一致、操作可解释、反馈明确和字段可读的基础原则。

规则分级建议：

- 必须：影响一致性、可用性、数据安全或误操作风险的规则。
- 默认：多数场景推荐采用的规则，业务有明确理由时可调整。
- 可选：增强体验的能力，根据复杂度和成本决定是否提供。
- 业务定义：依赖业务规则、权限、性能或风险等级的内容，由业务或技术输入确认。

## 2. 表格与左树结构选择

当业务对象数量容易达到上百或上千条，或用户需要按组织、区域、分组、分类管理时，优先考虑左树结构配合表格展示。左树用于切换管理范围或分类，右侧表格用于展示当前节点下的明细数据和主要操作。

使用左树结构时：

- 左树切换后，右侧表格应回到第一页，并基于当前树节点重新请求数据。
- 搜索、筛选、排序和分页必须受当前左树范围约束。
- 返回列表时应恢复左树节点、搜索筛选条件、排序、页码和纵向滚动位置。
- 左树节点为空、无权限或加载失败时，应给出对应状态，不得让右侧表格展示与当前范围不一致的数据。

## 3. 表格整体布局

1. 表格上方的查询或筛选区域。
2. 表格头部操作区。
3. 表格主体。
4. 表格底部分页区。

布局规则：

- 主操作、批量操作、查询筛选、刷新、列设置等入口必须有稳定位置，不得互相混淆。
- 查询条件较复杂时，应放在表格上方独立区域；查询条件较轻量时，可放在表格头部右侧。
- 不存在对应能力时不展示控件，不保留空白占位。
- 页面同时存在概览卡片、左树、搜索筛选和表格时，所有筛选范围必须统一进入同一查询状态。

## 4. 表格头部操作区

### 4.1 左侧操作区

#### 操作排列

- 新增、创建等最高频主操作默认使用主按钮样式，位于操作区首位，不收入下拉菜单。
- 批量操作优先外放高频操作，常规建议外放 2-4 个，极限不超过 7 个；超出部分收入“更多”菜单，点击“更多”按钮后通过下拉面板展示剩余操作。
- 其他操作按使用频率从高到低排列。
- 危险或不可逆操作是否外放、是否二次确认，由业务风险等级定义。
- 无权限操作默认隐藏；如果用户需要理解能力存在但当前不可用，可置为禁用并说明原因。

#### 按钮状态

| 操作类型 | 未勾选时 |
| --- | --- |
| 新增、导入 | 可点击 |
| 删除、启用、禁用等对象操作 | 禁用 |
| 导出 | 可点击；未勾选时导出当前查询范围内的结果，勾选后导出选中对象 |

- 依赖勾选的操作在未勾选时必须禁用。
- 悬浮禁用按钮时提示：`请先勾选对象再执行操作`。
- 勾选后只激活当前选择范围允许执行的操作。
- 勾选、取消和清空后，按钮状态实时更新。

#### 勾选数量限制

- 默认不限制勾选数量。
- 选中后持续展示已选数量和清空入口，默认放在分页器左侧。
- 存在性能限制时，由业务或技术提供上限 `X`，不得自行设置。
- 表头批量选择超过上限时提示：`最多勾选 X 条数据，将按顺序选择前 X 条数据`；确认后选择前 `X` 条，取消后保持原选择。
- 逐条勾选达到上限后不再加入新对象，并提示：`已达到勾选数量上限（X 个），请先移除已选对象后再继续选择`。

#### 不支持操作的对象

- 当表格仅存在一个依赖勾选的批量操作，且对象明确不支持该操作时，可禁止勾选并说明原因。
- 当存在多个批量操作，或对象对不同操作的可执行性不同，应允许统一勾选，并在执行具体操作时校验、跳过不满足条件的对象。
- 跳过对象必须计入失败结果并展示原因，不得静默忽略。
- 行操作和批量操作的权限判断应保持一致，不得出现同一对象行内可操作、批量不可操作且无解释的冲突。

#### 批量操作反馈

- 执行前明确操作对象数量；高风险操作按业务规则二次确认。
- 全部成功：提示成功数量。
- 部分失败：提示 `成功 X 个，失败 Y 个`，并展示失败对象和原因。
- 全部失败：明确提示失败，并展示全部失败对象和原因。
- 完成后刷新数据并保留搜索、筛选、排序和页码；清除失效的勾选状态。
- 批量操作执行中，对应按钮进入 loading 或禁用状态，避免重复提交。

### 4.2 右侧查询区

右侧查询区用于承载轻量筛选、基础搜索和刷新入口。筛选和搜索组件数量决定展示方式：

- 当筛选和搜索组件在 4 个以内时，直接使用选择框、搜索框和刷新 icon 按钮平铺展示。
- 搜索框和刷新 icon 按钮始终排在最右侧，刷新 icon 按钮位于搜索框右侧；选择框排在左侧。
- 当搜索框与选择框同时存在时，选择框在前，搜索框在后。
- 当筛选和搜索组件超过 4 个时，使用高级搜索组件展示，避免头部查询区过长。
- 基础搜索框一般只有一个，一个搜索框内集合多个字段的搜索能力。
- 如需让用户切换搜索字段，可使用分类搜索框支持搜索字段切换。
- 如果业务明确要求多个搜索框，则按业务要求展示多个基础搜索框。
- 不存在对应能力时不展示控件，不保留空白。

## 5. 搜索与筛选

### 5.1 模式选择

根据搜索筛选组件数量和查询复杂度选择展示方式：

- 筛选和搜索组件在 4 个以内时，优先在表格头部右侧平铺展示选择框、搜索框和刷新 icon 按钮。
- 筛选和搜索组件超过 4 个时，使用高级搜索组件展示。
- 字段多、操作符复杂、查询条件需要组合管理或需要可视化展示条件标签时，使用高级搜索组件。
- 两种展示方式不应在同一查询范围内重复生成同类控件，避免维护两套不一致状态。

### 5.2 轻量搜索与筛选

- 选择框用于状态、类型、时间等高频结构化条件。
- 搜索框用于名称、ID、描述等关键字字段。
- 搜索框只搜索配置支持的字段，并提示检索范围。
- 基础搜索框一般只有一个，优先在一个搜索框内集合多个字段的搜索能力。
- 需要切换搜索字段时，使用分类搜索框承载字段切换能力。
- 业务明确要求多个搜索框时，可展示多个基础搜索框。
- 筛选和搜索必须能够组合生效。
- 条件变化后回到第一页，并保留当前排序。

### 5.3 高级搜索

- 高级搜索用于字段较多、条件组合较复杂或头部区域无法平铺承载的场景。
- 条件以标签形式展示，支持添加、修改和删除。
- 检索字段及操作符由业务规则和配置决定。
- 关键时间可作为默认条件；不可清除时必须始终保留。
- 时间快捷范围和最大跨度使用业务配置，不得写死。
- 清空移除可清除条件；重置恢复业务默认条件。
- 存在检索按钮时，条件编辑后点击检索才提交。
- 执行检索后回到第一页，并保留当前排序。

### 5.4 通用联动

- 搜索、筛选、概览、左树、排序和分页使用同一查询状态。
- 搜索或筛选变化后回到第一页。
- 刷新保留当前搜索、筛选、排序和页码。
- 概览或表格字段产生的筛选必须回显到当前搜索组件。
- 返回列表时恢复搜索、筛选、排序、页码和纵向滚动位置。
- 不得同时维护两份不一致的筛选状态。

## 6. 表格刷新

- 表格刷新入口应与筛选、搜索、列设置、批量检索等入口区分清楚，不得混淆。
- 同一张表格不得重复生成多个刷新入口。
- 刷新只重新请求当前表格数据，保留左树范围、概览选择、搜索、筛选、排序和页码。
- 刷新期间保留已有表格数据并显示加载状态，避免表格闪空和重复触发。
- 手动刷新保留当前页；当前页无数据时回到最后有效页。

## 7. 表格字段与列设计

### 7.1 默认显示列

需求已明确默认列时直接采用；未明确时，选择能够完成以下判断的最小字段集合：

1. 当前对象是谁。
2. 是否需要关注或处理。
3. 当前状态或结果是什么。
4. 关键变化发生在什么时间。

同时遵守：

- 操作列始终展示、固定右侧且不可隐藏。
- 有批量操作时，选择列始终展示并固定左侧。
- 至少固定一个主要识别列，保证横向滚动后仍能识别当前行。
- 空间不足时优先隐藏追溯信息、辅助标识和次要判断字段。
- 不得因接口字段较多而默认全部展示。
- 非默认字段可通过列设置恢复，业务禁止展示的字段除外。
- 受权限限制的字段不得展示；字段隐藏原因需要被解释时，可在列设置或空态中说明。

### 7.2 字段展示

表格字段默认使用普通文本展示，保持信息清晰、稳定和易扫描。只有当字段需要表达可点击、可切换、状态、风险、类型或统计对象时，才使用更强的展示形式。

| 字段类型 | 推荐展示形式 | 适用说明 |
| --- | --- | --- |
| 名称 | 链接色文本 | 用于对象名称、策略名称、规则名称、任务名称等。点击后打开对应详情页、抽屉详情页或编辑页面。 |
| 启用/禁用状态 | 可变更标签 | 使用“图标 + 正文文字（启用/禁用）+ 下拉icon”。点击下拉icon后出现启用/禁用选择面板，用于直接切换状态。 |
| 设备/服务器运行状态 | 点状标签 | 使用“彩色圆点 + 正文文字”。例如绿色圆点 + 在线表示设备在线，灰色圆点表示离线，橙色圆点表示告警。 |
| 连续性状态 | icon标签 | 用于任务状态、流程状态等有阶段变化的状态，例如待开始、进行中、已完成、已结束、任务失败。 |
| 风险等级 | 深色标签 | 使用彩色背景 + 白色文字，适用于告警事件严重/高危/中危/低危、数据分级分类等具有明显风险倾向的字段。 |
| 威胁标签 | 浅色标签 | 使用淡色背景 + 同色系深色文字，适用于攻击类型、威胁类型、检测命中标签等安全语义字段。 |
| 标签或类型 | 浅灰色标签 | 适用于没有明显风险倾向的非核心字段。如果只有2种类型且希望颜色上有所区分，可使用绿色和蓝色的浅色标签。 |
| 统计数字 | 蓝色数字 | 用于可查看具体对象的统计值，例如分配IP地址数、关联资产数、命中规则数。悬浮或点击时展示对应具体对象。 |
| 进度 | 进度条 + 数量统计 | 用于扫描任务、升级任务、批处理任务等需要展示整体完成度的字段。进度条展示完成比例，同时展示数量统计，例如12/100。 |

- 对象名称或主要标识放在业务字段前部。
- 状态、等级使用项目已有组件和颜色语义。
- 时间使用平台统一格式或产品统一格式。
- 无值统一显示 `-`。
- 超长内容单行截断，悬浮展示完整内容。
- 禁止平均分配列宽：
  - 固定内容列使用固定宽度。
  - 短文本列使用最小宽度和内容自适应。
  - 长文本列设置最大宽度并省略。
  - 主要对象列承担剩余弹性空间。
- 可调整列宽的最小值必须完整容纳表头和表头图标。
- 双行展示只用于强关联的主次信息，不用于单纯解决文本过长。
- 字段内存在可点击对象卡片、详情卡片或跳转链接时，该交互不得同时触发行详情。
- 拆解页面清单时，表格区不仅要列出字段名称，还要说明每个字段的展示形式。不要只写“名称、状态、类型、数量”等字段列表。

## 8. 排序

### 8.1 必须支持排序的字段

表格中存在以下字段时，对应表头必须提供可见、可操作的排序入口：

- 优先级类字段。
- 等级类字段。
- 所有时间类字段。
- 业务定义了明确顺序的分类字段。

首次排序方向：

- 优先级、等级：业务顺序从高到低。
- 时间：最新在前。
- 分类字段：按业务字典顺序；未定义时按展示名称升序。

枚举字段必须按业务枚举顺序排序，不得直接按显示文案或字符串值排序。

### 8.2 默认排序

支持排序不等于默认排序。不得根据字段是否存在直接决定默认排序字段。按以下顺序确定：

1. 需求或业务规则已明确：直接采用。
2. 存量页面：保持现有默认排序。
3. 新页面根据核心浏览顺序确定：
   - 日志、事件、告警等实时记录按关键发生时间最新在前。
   - 策略、规则等存在生效顺序的数据按业务优先级从高到低。
   - 其他列表复用同类页面；无法判断时列为前置确认项。

业务规则应返回默认排序字段、业务顺序及接口升降序映射。

- 默认只激活一个主排序字段。
- 默认激活列必须显示排序状态。
- 切换排序后回到第一页，并保留搜索和筛选条件。
- 排序不得破坏置顶对象、特殊对象位置等业务不变量。

## 9. 单行操作

- 操作列最多直接展示 3 个操作。超过 3 个操作时，将剩余操作统一收纳到“更多”操作中；点击“更多”后通过下拉面板展示剩余操作。
- 常见策略、规则、配置类表格的操作顺序通常为：编辑、复制、删除。
- 数据查看类表格的第一个操作通常为：详情。
- 多操作排序应按使用频率和业务重要性排列，常用操作优先直接展示，低频操作优先放入“更多”。
- 危险或不可逆操作优先收入更多菜单。
- 操作列固定右侧，不随横向滚动移动。
- 启停、状态切换等轻量操作可在行内完成。
- 存在复杂表单、关联影响、批量校验或高风险变更时，不得使用行内直接修改。
- 操作后即时刷新状态并提供成功或失败反馈。
- 字段操作和操作列点击不得触发行主交互。
- 无权限行操作默认隐藏；如保留禁用态，必须说明无权限或不可操作原因。

## 10. 列设置与滚动

- 支持显示/隐藏、顺序和宽度调整，并按账号保存。
- 列设置属于表格布局能力，入口位置应稳定，不得与筛选、搜索框和批量检索入口混淆。
- 操作列和选择列不可通过列设置隐藏。
- 横向滚动条出现时应保持可见。
- 纵向滚动时表头保持可见。
- 1366 和 1920 宽度下，核心判断字段应默认可见。
- 除日志等字段较多场景外，默认列应尽量避免横向滚动。
- 不得为消除滚动而过度压缩列宽，导致大面积省略。

## 11. 分页与选中信息

- 分页放在表格底部，展示总数、当前页和每页数量。
- 页码、每页数量和总数必须与当前查询一致。
- 搜索、筛选、左树或排序变化后回到第一页。
- 手动刷新保留当前页；当前页无数据时回到最后有效页。
- 有批量选择时展示选中数量和清空入口，默认放在分页器左侧。
- 默认选择范围为当前页。
- 如支持跨页选择，必须明确“当前页全选”和“全部结果全选”的区别。
- 全部结果全选必须受当前搜索、筛选、左树、权限范围约束。
- 清空选择应清除全部已选对象，而不只是当前页。
- 跨页选择、全选范围和清空规则必须由业务明确。

## 12. 状态与异常

### 12.1 加载状态

- 首次加载可展示骨架屏或表格加载态。
- 搜索、筛选、排序、分页切换时保留表格结构并展示加载状态。
- 手动刷新期间保留已有数据，避免闪空。
- 批量操作执行中，对应操作按钮进入 loading 或禁用状态，避免重复提交。

### 12.2 空状态

- 初始无数据时展示创建、导入、配置或接入引导。
- 搜索无结果时展示“未找到匹配结果”，并提供清空搜索或调整筛选入口。
- 筛选无结果时展示当前筛选条件导致无结果，并提供重置筛选入口。
- 无权限数据为空时提示权限范围限制，不引导创建数据。
- 左树范围为空时，右侧表格空态应说明当前范围没有数据，而不是全局没有数据。

### 12.3 错误状态

- 查询失败时保留当前查询条件，并提供重试入口。
- 分页请求失败时不得清空已有查询状态。
- 批量操作失败必须展示失败原因；原因来自接口时优先使用接口返回。
- 当前页因数据变化失效时，自动回到最后有效页。
- 局部字段加载失败时，优先保留行数据并在字段位置展示失败或空值说明，避免整表不可用。

### 12.4 权限状态

- 无权限查看的数据字段不得展示。
- 无权限操作默认隐藏；若用户需要知道能力存在但不可用，可禁用并说明原因。
- 批量操作中部分对象无权限时，执行结果必须展示无权限对象及原因。
- 行操作和批量操作的权限判断必须一致。

## 13. 通用联动规则

- 搜索、筛选、概览、左树、排序、分页和选中状态必须基于同一查询上下文。
- 查询范围变化后，清除不再有效的选中对象。
- 搜索、筛选、左树和排序变化后回到第一页。
- 刷新保留当前搜索、筛选、排序、页码和左树范围。
- 返回列表时恢复搜索、筛选、排序、页码、左树范围和纵向滚动位置。
- 概览卡片、字段点击、标签点击等产生的筛选必须回显到当前搜索组件。
- 不得同时维护两份不一致的筛选状态。
