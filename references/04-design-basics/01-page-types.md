# 页面类型与页面元素说明

本文件用于在生成Demo设计说明书和Wireframe / ASCII线框图时，统一判断页面类型、页面骨架和通用页面元素布局。使用时先选择页面类型，再套用页面元素说明。

## 1. 页面类型

页面类型用于判断页面整体骨架、入口层级和内容承载方式。线框图中的“页面标题栏”是标题区域占位，实际生成时必须按“2.1 页面标题栏”选择对应标题栏结构。

### 1.1 基础表格页

用于对同一类型对象进行集中查询和管理，通常包含搜索、筛选、排序、分页、新增、编辑、删除、导入导出及批量操作，例如资产列表、用户列表、策略列表、漏洞列表和白名单列表。

#### 页面结构

```text
┌──────────┬───────────────────────────────────────────────────┐
│          │ 页面标题栏 (48px，紧贴左侧导航)                   │
│  左侧    ├───────────────────────────────────────────────────┤
│  深色    │ ↓ 间距 8px                                        │
│  导航    │ ┌─────────────────────────────────────────────┐  │
│          │ │ Toolbar (上边距 8px, 无左右内间距)           │  │
│          │ │ ↓ 间距 8px                                  │  │
│          │ │ Table (无左右内间距)                         │  │
│          │ │ Pagination (吸附底部, 40px, 顶部分割线 1px) │  │
│          │ └─────────────────────────────────────────────┘  │
│          │         ← 12px →                    ← 12px →     │
└──────────┴───────────────────────────────────────────────────┘
```

### 1.2 左树表格页

用于管理具有组织、区域、分组或层级关系的数据，左侧通过树形结构选择范围，右侧展示当前节点下的数据列表，例如组织机构与用户、资产分组与设备、站点与主机、策略组与策略。

#### 页面结构

```text
┌──────────┬───────────────────────────────────────────────────────┐
│          │ 页面标题栏 (48px，紧贴左侧导航)                       │
│  左侧    ├───────────────────────────────────────────────────────┤
│  深色    │ ↓ 间距 8px                                            │
│  导航    │ ┌──────────────────────────────────────────────────┐│
│          │ │ 左侧树   │ 右侧内容区                              ││
│          │ │ (240px)  │ Toolbar (上边距 8px)                    ││
│          │ │          │ ↓ 间距 8px                               ││
│          │ │          │ Table                                    ││
│          │ │          │ Pagination (吸附底部, 40px, 1px 分割线) ││
│          │ └──────────────────────────────────────────────────┘│
│          │         ← 12px →                       ← 12px →      │
└──────────┴───────────────────────────────────────────────────────┘
```

### 1.3 配置表单页

用于完成字段较多、信息分组复杂或需要独立保存的配置。配置项超过约1.5屏时，需要考虑页面锚点或页内导航。页面修改未保存时，离开页面需要弹窗提醒用户保存未生效，并提供保存、放弃或继续编辑。

#### 页面结构

```text
┌──────────┬───────────────────────────────────────────────────┐
│          │ 页面标题栏 (48px，紧贴左侧导航)                   │
│  左侧    ├───────────────────────────────────────────────────┤
│  深色    │ ↓ 间距 8px                                        │
│  导航    │ ┌─────────────────────────────────────────────┐  │
│          │ │ 表单配置内容区                              │  │
│          │ │ (左右 20px + 卡片 12px = 视觉总间距 32px)   │  │
│          │ │                                             │  │
│          │ │ 遵循 pattern-form.md 表单规范               │  │
│          │ │                                             │  │
│          │ ├─────────────────────────────────────────────┤  │
│          │ │ 底部按钮区 (56px，按钮左对齐，按钮间距 8px)   │  │
│          │ │ [保存]  [恢复默认]                           │  │
│          │ └─────────────────────────────────────────────┘  │
│          │         ← 12px →                    ← 12px →     │
└──────────┴───────────────────────────────────────────────────┘
```

### 1.4 概览表格页

用于同时展示某类对象的总体情况和明细数据。页面上方通常提供数量、状态分布、风险等级或处置进度等概览指标，下方通过表格展示具体对象，例如告警概览、漏洞概览、资产风险概览和任务执行概览。

#### 页面结构

```text
┌──────────┬───────────────────────────────────────────────────────┐
│          │ 页面标题栏 (48px，紧贴左侧导航)                       │
│  左侧    ├───────────────────────────────────────────────────────┤
│  深色    │ ↓ 间距 8px                                            │
│  导航    │ B: 筛选区（可选，右对齐：日期范围 + 刷新 icon）       │
│          │                                                       │
│          │ ↓ 间距 8px                                            │
│          │ ┌─────────────────────────────────────────────────┐  │
│          │ │ C: 概览卡片 (高度 166px)                        │  │
│          │ │ 统计概览内容（数字指标、趋势图、状态分布等）     │  │
│          │ └─────────────────────────────────────────────────┘  │
│          │                                                       │
│          │ ↓ 间距 8px                                            │
│          │ ┌─────────────────────────────────────────────────┐  │
│          │ │ D: 表格内容卡片（基础表格页）                    │  │
│          │ │ Toolbar + Table + Pagination                     │  │
│          │ └─────────────────────────────────────────────────┘  │
│          │         ← 12px →                        ← 12px →     │
└──────────┴───────────────────────────────────────────────────────┘
```

### 1.5 概览左树表格页

用于在同一页面中同时展示整体概览、分类导航和数据明细。页面顶部展示数量、状态、风险等级或处置进度等概览指标；下方采用左树右表格结构，左侧切换数据范围，右侧展示明细数据。

#### 页面结构

```text
┌──────────┬───────────────────────────────────────────────────────┐
│          │ 页面标题栏 (48px，紧贴左侧导航)                       │
│  左侧    ├───────────────────────────────────────────────────────┤
│  深色    │ ↓ 间距 8px                                            │
│  导航    │ ┌─────────────────────────────────────────────────┐  │
│          │ │ 概览卡片（数值 / 状态 / 风险 / 进度）            │  │
│          │ └─────────────────────────────────────────────────┘  │
│          │ ↓ 间距 8px                                            │
│          │ ┌─────────────────────────────────────────────────┐  │
│          │ │ 左侧树   │ 右侧内容区                              │  │
│          │ │ (240px)  │ Toolbar + Table + Pagination            │  │
│          │ └─────────────────────────────────────────────────┘  │
│          │         ← 12px →                        ← 12px →     │
└──────────┴───────────────────────────────────────────────────────┘
```

### 1.6 Dashboard

用于展示系统整体运行状态和核心态势，通常包含关键指标、趋势图、风险分布、排行、来源、资产状态和待处理事项，适合作为控制台首页、运营驾驶舱或态势总览。Dashboard 参考概览表格页的页面结构，但去掉表格内容卡片，页面全部由概览卡片组成；概览卡片之间间距为 8px；卡片数量可根据实际需求和展示内容宽度增减，示例中可按 2 个卡片或 1-4 个卡片进行组合；每个卡片展示不同的数据展示形式，例如数字指标、趋势图、状态分布、排行、环比或待办事项。

#### 页面结构

```text
┌──────────┬───────────────────────────────────────────────────────┐
│          │ 页面标题栏 (48px，紧贴左侧导航)                       │
│  左侧    ├───────────────────────────────────────────────────────┤
│  深色    │ ↓ 间距 8px                                            │
│  导航    │ ┌─────────────────────────────────────────────────┐  │
│          │ │ 概览卡片 1              │ ← 8px → │ 概览卡片 2       │  │
│          │ │ 数字指标 / 趋势图       │         │ 状态分布 / 排行  │  │
│          │ └─────────────────────────────────────────────────┘  │
│          │ ↓ 间距 8px                                            │
│          │ ┌─────────────────────────────────────────────────┐  │
│          │ │ 可继续按 1-4 个卡片组合，数量随内容宽度增减       │  │
│          │ │ 每个卡片展示不同的数据展示或运营信息             │  │
│          │ └─────────────────────────────────────────────────┘  │
│          │         ← 12px →                        ← 12px →     │
└──────────┴───────────────────────────────────────────────────────┘
```

### 1.7 下钻详情页

用于承载单个对象的完整信息和深度分析，通常由列表或图表点击进入。展示详情时优先使用抽屉详情页，慎用完整下钻页面。只有当详情信息量很大、包含多个Tab或还需要继续下钻查看详情时，才采用下钻详情页。

#### 页面结构

```text
┌──────────┬───────────────────────────────────────────────────────┐
│          │ 下钻页标题栏                                          │
│  左侧    ├───────────────────────────────────────────────────────┤
│  深色    │ ↓ 间距 8px                                            │
│  导航    │ ┌─────────────────────────────────────────────────┐  │
│          │ │ 单对象详情概览卡片                              │  │
│          │ │ ┌────────┬──────────────────────────────┬─────┐ │  │
│          │ │ │ 对象图标 │ 核心信息区                 │ 右侧操作区 │ │  │
│          │ │ │        │ 第一行：对象名称标题       │         │ │  │
│          │ │ │        │ 第二行：辅助信息           │         │ │  │
│          │ │ └────────┴──────────────────────────────┴─────┘ │  │
│          │ └─────────────────────────────────────────────────┘  │
│          │ ↓ 间距 8px                                            │
│          │ ┌─────────────────────────────────────────────────┐  │
│          │ │ 内容卡片（可为表格、详情分区、图表、关联列表等） │  │
│          │ └─────────────────────────────────────────────────┘  │
│          │         ← 12px →                        ← 12px →     │
└──────────┴───────────────────────────────────────────────────────┘
```

### 1.8 弹窗表单页

用于完成内容较少、操作路径较短且不需要离开当前页面的新增或编辑操作，例如新增标签、修改名称、配置通知方式、填写处置意见和设置有效期。弹窗结构应包含标题栏、内容区和底部按钮栏；内容区适合承载轻量配置分区、少量字段和必要说明。底部按钮通常为“确定”“取消”，并右对齐。

#### 页面结构

```text
┌──────────────────────────────────────────────────────────────┐
│ 标题栏 Header                                   关闭 icon  × │
│ 标题文字左对齐，关闭 icon 在右侧，距右边缘 16px              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                           Body 内容区                         │
│                                                              │
│  ┌─ 分区标题# 基础配置 ───────────────────────────────────┐   │
│  │ 配置名称     [____________________]                   │   │
│  │ 配置类型     [下拉选择器 ▼]                            │   │
│  │ 生效状态     ( ● 启用  ○ 禁用 )                        │   │
│  └───────────────────────────────────────────────────────┘   │
│                                                              │
│  ┌─ 分区标题# 高级配置 ───────────────────────────────────┐   │
│  │ 有效期       [日期选择器 ▼]                             │   │
│  │ 优先级       [下拉选择器 ▼]                             │   │
│  │ 备注         [____________________________________]    │   │
│  └───────────────────────────────────────────────────────┘   │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│                                                [主按钮] [取消] │
│                              Footer 按钮栏                    │
└──────────────────────────────────────────────────────────────┘
```

#### 内容区说明

- 内容区适合承载轻量配置，配置项较少时可以不需要配置小标题。
- 每个配置小标题下放置若干配置项，配置项可采用输入框、选择框、单选框、日期选择器等基础控件。
- 弹窗表单页应避免承载过多分区或长表单；如果内容中等复杂、需要保留当前页面上下文或需要内部滚动，优先改用抽屉表单页。
- 底部按钮栏通常右对齐，主按钮在取消按钮左侧。

### 1.9 弹窗列表页

用于在当前操作过程中临时查询并选择一项或多项已有数据，通常包含搜索、筛选、勾选和关闭操作，例如选择资产、选择用户、选择策略模板、选择通知对象和选择关联告警。

#### 页面结构

```text
┌──────────────────────────────────────────────────────────────┐
│ 标题栏 Header                                                × │
│ 标题文字左对齐，关闭 icon 在右侧，距右边缘 16px              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                           Body 内容区                         │
│                                                              │
│  ┌───────────────────────────────────────────────────────┐   │
│  │ Toolbar                                               │   │
│  │ [按钮区]                    [选择器] [搜索框] [刷新]  │   │
│  │ ↓ 间距 8px                                            │   │
│  │ Table                                                 │   │
│  │ □ 名称       类型       状态       更新时间     操作   │   │
│  │ □ 示例对象A  设备       在线       2026-08-01   查看   │   │
│  │ □ 示例对象B  策略       启用       2026-08-02   查看   │   │
│  │ Pagination                                            │   │
│  └───────────────────────────────────────────────────────┘   │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│                                                       [关闭] │
│                              Footer 按钮栏                    │
└──────────────────────────────────────────────────────────────┘
```

#### 内容区说明

- 内容区放置一个“工具栏 + 表格”结构，工具栏规则参考“2.2 表格工具栏”。
- 表格用于展示可查询、可选择或可查看的对象列表，可按场景决定是否展示勾选列。
- 弹窗列表页底部按钮通常只保留“关闭”，不使用主按钮和取消按钮组合。
- 如果列表需要复杂筛选、长时间浏览或承载较多行内操作，优先改用抽屉列表页。

### 1.10 抽屉表单页

用于完成中等复杂度的新增或编辑操作，在保留当前页面上下文的同时提供比弹窗更大的操作空间，例如新增资产、编辑检测规则、配置告警处置动作、创建扫描任务和修改设备信息。抽屉结构应包含标题栏、内容区和底部按钮栏；内容区内部可滚动，适合承载分组配置、若干字段和说明信息。

#### 页面结构

```text
┌──────────────────────────────────────────────────────────────┐
│ 标题栏 Header                                   关闭 icon  × │
│ 标题文字左对齐，关闭 icon 在右侧，距右边缘 16px              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                           Body 内容区                         │
│                         内容区内部滚动                         │
│                                                              │
│  ┌─ 分区标题# 基础配置 ───────────────────────────────────┐   │
│  │ 配置名称     [____________________]                   │   │
│  │ 配置类型     ( ○ 类型A  ○ 类型B  ● 类型C )            │   │
│  │ 启用状态     [开关]                                   │   │
│  └───────────────────────────────────────────────────────┘   │
│                                                              │
│  ┌─ 分区标题# 网络配置 ───────────────────────────────────┐   │
│  │ 服务器地址   [____________________]                   │   │
│  │ 端口         [____]                                   │   │
│  │ 协议类型     [下拉选择器 ▼]                            │   │
│  │ 认证方式     ( ○ 密码认证  ○ 证书认证  ○ 免认证 )      │   │
│  └───────────────────────────────────────────────────────┘   │
│                                                              │
│  ┌─ 分区标题# 补充说明 ───────────────────────────────────┐   │
│  │ 备注         [____________________________________]    │   │
│  └───────────────────────────────────────────────────────┘   │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ [主按钮] [取消]                                               │
│                           Footer 按钮栏                      │
└──────────────────────────────────────────────────────────────┘
```

#### 内容区说明

- 内容区适合按配置小标题进行分组，每个分区内放置若干配置项。
- 每个配置项可采用输入框、选择框、单选框、开关、日期选择器等基础控件。
- 配置项默认按纵向顺序排列，不做两列排布。
- 功能层面的说明可放在配置分组标题下方或页面全局说明区；字段级说明默认通过字段右侧的小 `i` 提示图标展示。
- 底部按钮栏通常包含主按钮和取消按钮，按钮左对齐排列，右侧不设置按钮位。

### 1.11 抽屉列表页

用于在不离开当前页面的情况下查看某个对象关联的一组数据，通常支持搜索、筛选、分页或简单操作，例如查看资产关联告警、策略关联设备、用户操作记录、漏洞影响资产和任务执行结果。

#### 页面结构

```text
┌──────────────────────────────────────────────────────────────┐
│ 标题栏 Header                                   关闭 icon  × │
│ 标题文字左对齐，关闭 icon 在右侧，距右边缘 16px              │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                           Body 内容区                         │
│                         内容区内部滚动                         │
│                                                              │
│  ┌───────────────────────────────────────────────────────┐   │
│  │ Toolbar                                               │   │
│  │ [按钮区]                    [选择器] [搜索框] [刷新]  │   │
│  │ ↓ 间距 8px                                            │   │
│  │ Table                                                 │   │
│  │ □ 名称       类型       状态       更新时间     操作   │   │
│  │ □ 示例对象A  告警       未处理     2026-08-01   查看   │   │
│  │ □ 示例对象B  告警       已恢复     2026-08-02   查看   │   │
│  │ Pagination                                            │   │
│  └───────────────────────────────────────────────────────┘   │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ [上一个] [下一个] [关闭]                                      │
│                           Footer 按钮栏                      │
└──────────────────────────────────────────────────────────────┘
```

#### 内容区说明

- 内容区放置一个“工具栏 + 表格”结构，工具栏规则参考“2.2 表格工具栏”。
- 表格用于展示当前对象关联的数据列表，可支持筛选、搜索、分页、查看详情或简单行内操作。
- 抽屉列表页底部按钮通常只保留“关闭”，按钮左对齐排列，右侧不设置按钮位。
- 如果需要查看某条日志或记录的完整字段，可从行内操作进入日志详情页。

### 1.12 抽屉详情页

用于快速查看单个对象的主要信息、关联信息和局部内容，适合信息量中等且用户查看后需要继续留在原列表中操作的场景，例如告警快速详情、资产基础详情、漏洞摘要、任务执行详情和用户登录记录详情。

#### 页面结构


- 单对象详情概览卡片的核心信息区分为两行：第一行是 14 号加粗的对象名称标题，第二行是辅助信息，例如设备类型、所属分组、地理位置。
- 内容卡片可承载描述列表、表格、图表、时间线或其他局部内容；当内容较多时可配置 Tab 分区，但 Tab 行与内容区必须上下分离。

## 2. 页面元素说明

页面元素说明用于补充页面类型中的通用部件布局。生成页面内容描述和线框图时，优先复用本节规则。

### 2.1 单对象详情概览卡片

单对象详情概览卡片用于承载一个对象的身份识别、核心状态和快捷操作，常用于下钻详情页、抽屉详情页等对象详情场景，结构如下：

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ [图标]  设备名称 AF-1000                                      [启用][编辑][更多▼] │
│         设备类型 AF   所属分组 广州办事处   地理位置 广东省/广州市/番禺区          │
└──────────────────────────────────────────────────────────────────────────────┘
```

结构规则：

- 左侧为对象图标；中间为核心信息区，两行合并展示在卡片主体内：第一行是 14 号加粗对象名称标题，第二行是辅助信息、分类标签、归属范围或地理位置等摘要信息。
- 右侧为操作按钮，通常放 1 个主按钮 + 1 个普通按钮；如果还有其他按钮，则第三个按钮使用“更多”按钮，点击后以下拉形式展示其他按钮。
- 单对象详情概览卡片应作为独立卡片使用；当下方还有内容卡片时，两者之间固定 8px 间距。

### 2.2 页面标题栏

页面标题栏根据页面进入方式和页面层级选择对应结构。

#### 基础标题栏

适用于一级导航页面、普通列表页、普通配置页、普通详情页。

结构：`[页面标题]`

#### 下钻页标题栏

适用于从列表、详情、对象卡片、按钮入口进入的二级或三级页面。

结构：`[返回入口] [页面标题]`

要求：

- 返回入口位于标题左侧。
- 页面标题表达当前对象或当前任务。
- 返回入口回到上一级页面或来源页面。

#### 分层 Tabs 页标题

适用于页面标题下存在同级Tab分区的页面。

结构：`[页面标题] [纵向分割线] [Tab1] [Tab2]`

要求：

- 页面标题、纵向分割线和Tab在同一行展示完整。
- 分割线为纵向分割线，用于分隔页面标题与Tab组。
- Tab行不是内容区的一部分。
- Tab下方内容区是独立容器。
- 不要把Tab写成标题右侧操作。

### 2.3 表格工具栏

表格工具栏用于承载表格上方的新增、批量操作、筛选、搜索、刷新等操作。适用于基础表格页、左树表格页、概览表格页、概览左树表格页，以及弹窗列表页、抽屉列表页中的表格区域。

#### 结构

Toolbar 由两个区域组合而成，从左到右依次为：

```text
┌──────────────────────────────────────────────────────────────────────┐
│ [按钮区]                               [搜索筛选区]                │
│  主按钮 普通按钮 ... 更多▼        [复合日期] [选择器] [搜索] [刷新] │
└──────────────────────────────────────────────────────────────────────┘
```

#### 布局规则

- 左侧为按钮区，优先放主按钮、普通按钮、批量操作和更多操作。
- 左侧按钮数量最多 7 个，超过 7 个时将低频按钮收纳到“更多”按钮中。
- 右侧为搜索筛选区，用于承载筛选与检索条件。
- 搜索筛选区组件排序顺序依次为：复合日期筛选器、选择器、搜索框。
- 当筛选条件数量在 5 个以内时，优先平铺为单个筛选条件，不使用高级搜索。
- 当筛选条件超过 5 个时，改用 idux 高级搜索组件。
- 高级搜索组件的视觉样式可视为一个搜索框，内部集成多个条件筛选与搜索能力。
- 当同时存在按钮区和搜索筛选区时，按钮区靠左，搜索筛选区靠右，中间留出弹性空白。
- 搜索框通常靠近刷新入口；刷新入口通常位于最右侧。
- 表格工具栏属于表格区的一部分，不要单独拆成独立页面区块。
